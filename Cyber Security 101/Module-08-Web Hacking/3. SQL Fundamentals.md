# SQL Fundamentals

## What is a Database ?

A database is an organized collection of data that can be:

- Stored
- Retrieved
- Updated
- Managed

Databases help applications store information efficiently.

### Examples

- User accounts (username, password)
- Social media posts and comments
- Online shopping orders
- Streaming watch history
- Security logs

### Real-World Example

Instagram stores:

```text
Username
Posts
Comments
Likes
Followers
```

inside databases.

There are two main types of databases:

## Relational Databases (SQL)

Relational databases store data in a structured format using:

- Tables
- Rows
- Columns

### Example

| ID | Name | Email |
|----|------|--------|
| 1 | John | john@gmail.com |
| 2 | Alice | alice@gmail.com |

### Characteristics

- Structured data
- Fixed schema
- Relationships between tables
- High accuracy

### Common Uses

- Banking systems
- E-commerce websites
- User authentication systems

### Examples

- MySQL
- MariaDB
- PostgreSQL
- Oracle Database

---

## Non-Relational Databases (NoSQL)

NoSQL databases store data in flexible formats.

### Example

```
 {
    _id: ObjectId("4556712cd2b2397ce1b47661"),
    name: { first: "Thomas", last: "Anderson" },
    date_of_birth: new Date('Sep 2, 1964'),
    occupation: [ "The One"],
    steps_taken : NumberLong(4738947387743977493)
}
```

### Characteristics

- Flexible structure
- No fixed schema
- Handles large amounts of varying data

### Common Uses

- Social media platforms
- Big data applications
- Real-time applications

### Examples

- MongoDB
- Cassandra
- Redis

---

## SQL vs NoSQL

| Feature | SQL | NoSQL |
|----------|------|--------|
| Structure | Fixed | Flexible |
| Storage | Tables | Documents/Key-Value |
| Relationships | Supported | Limited |
| Best For | Structured Data | Unstructured Data |

## Primary Key

## What is a Primary Key ?

A primary key uniquely identifies each row in a table.

### Example

| ID | Name |
|----|------|
| 1 | John |
| 2 | Alice |

Here:

```text
ID = Primary Key
```

### Rules

- Must be unique
- Cannot be duplicated
- One primary key per table

### Real-Life Example

```text
Student Roll Number
Employee ID
Passport Number
```

---

## Foreign Key

## What is a Foreign Key ?

A foreign key links one table to another.

### Example

#### Authors Table

| ID | Author_Name |
|----|-------------|
| 1 | Kevin Mitnick |
| 2 | Bruce Schneier |

#### Books Table

| Book_ID | Book_Name | Author_ID |
|----------|-----------|-----------|
| 1 | Book A | 1 |
| 2 | Book B | 2 |

Here:

```text
Author_ID = Foreign Key
```

because it references:

```text
Authors.ID
```

### Purpose

- Creates relationships between tables
- Prevents duplicate information
- Improves database organization

## What is SQL ?

## SQL (Structured Query Language)

SQL is the language used to interact with relational databases.

It allows users to:

- Create databases
- Create tables
- Insert data
- Retrieve data
- Update data
- Delete data

### Example

```sql
SELECT * FROM users;
```

This retrieves all records from the users table.

---

### Fast

SQL databases can process large amounts of data quickly.

### Example

## UPDATE Without WHERE

❌ Dangerous

```sql

SET name = "Updated";
```

Updates every row.

## DELETE Without WHERE

❌ Dangerous

```sql

```

Deletes every record.

✅ Safe

```sql

SET name = "Updated"
WHERE id = 1;
```

```sql
DELETE FROM books
WHERE id = 1;
```

## SQL Clauses

The DISTINCT clause is used to avoid duplicate records when doing a query, returning only unique values.

Let's use a query SELECT * FROM books and observe the results below.

<img width="965" height="210" alt="image" src="https://github.com/user-attachments/assets/42ecc376-58b0-4cb0-bf42-6cd8f38d3a05" />

The query's output displays all the content of the table books, and the record Ethical Hacking is displayed twice. Let's perform the query again, but this time, using the DISTINCT clause.

### DISTINCT

```sql
SELECT DISTINCT column_name
FROM table_name;
```

Returns only unique values and removes duplicate records from the result.

**Example:**

<img width="951" height="416" alt="image" src="https://github.com/user-attachments/assets/ddf35379-041c-4891-a8a5-b68b6bae1016" />

Returns each book name only once, even if duplicates exist.

---

### GROUP BY

```sql
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;
```

Groups rows with the same value together, often used with aggregate functions like COUNT(), SUM(), AVG(), MAX(), and MIN().

**Example:**

<img width="527" height="223" alt="image" src="https://github.com/user-attachments/assets/1c489927-33b5-4d81-9400-aaff6a2fa244" />

Counts how many times each book name appears.

---

### ORDER BY

```sql
SELECT column_name
FROM table_name
ORDER BY column_name ASC|DESC;
```

Sorts the query results.

- `ASC` → Ascending order (default)
- `DESC` → Descending order

**Example (Ascending):**

<img width="935" height="243" alt="image" src="https://github.com/user-attachments/assets/55f12591-e155-44be-9905-03919946e913" />

Shows oldest books first.

**Example (Descending):**

<img width="930" height="241" alt="image" src="https://github.com/user-attachments/assets/ae965c45-0199-4ebd-ab2b-7f4b8a88b33a" />

Shows newest books first.

---

### HAVING

```sql
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;
```

Filters grouped results after aggregation.

> Difference:
>
> - `WHERE` filters rows before grouping.
> - `HAVING` filters groups after grouping.

**Example:**

<img width="610" height="197" alt="image" src="https://github.com/user-attachments/assets/6a68b9fc-f765-4cd7-9a38-3d14ec6f2e88" />

Returns only grouped book names containing "Hack".

---

## Quick Comparison

| Clause | Purpose |
|----------|---------|
| DISTINCT | Remove duplicate results |
| GROUP BY | Group similar records together |
| ORDER BY | Sort query results |
| HAVING | Filter grouped/aggregated results |

---

## Execution Order (Easy to Remember)

```sql

FROM
WHERE

```

## SQL Fundamentals Summary

- Database = organized collection of data.
- Two types:
  - Relational (SQL) → structured data.
  - Non-Relational (NoSQL) → flexible/non-tabular data.
- Relational databases use:
  - Tables
  - Rows (records)
  - Columns (fields)
- Primary Key → uniquely identifies a record.
- Foreign Key → links tables together.
- SQL (Structured Query Language) is used to interact with relational databases.

## Database Commands
- `CREATE DATABASE` → create database.
- `SHOW DATABASES` → list databases.
- `USE` → select database.
- `DROP DATABASE` → delete database.

## Table Commands
- `CREATE TABLE` → create table.
- `SHOW TABLES` → list tables.
- `DESCRIBE` → view table structure.
- `ALTER TABLE` → modify table.
- `DROP TABLE` → delete table.

## CRUD Operations
- `INSERT` → Create data.
- `SELECT` → Read data.
- `UPDATE` → Update data.
- `DELETE` → Delete data.

## Clauses
- `FROM` → specify table.
- `WHERE` → filter rows.
- `DISTINCT` → remove duplicates.
- `GROUP BY` → group records.
- `ORDER BY` → sort results.
- `HAVING` → filter grouped results.

## Operators
- `LIKE` → pattern matching.
- `AND` → all conditions true.
- `OR` → any condition true.
- `NOT` → reverse condition.
- `BETWEEN` → range check.
- `=` `!=` `<` `>` `<=` `>=` → comparisons.

## Functions
### String Functions
- `CONCAT()` → join strings.
- `GROUP_CONCAT()` → combine row values.
- `SUBSTRING()` → extract text.
- `LENGTH()` → count characters.

### Aggregate Functions
- `COUNT()` → count rows.
- `SUM()` → total values.
- `MAX()` → largest/latest value.
- `MIN()` → smallest/earliest value.

## Key Idea
SQL = Database + Tables + CRUD + Clauses + Operators + Functions.
