# Windows Command Line 

## Introduction

Most users prefer a Graphical User Interface (GUI) because it is easy to use and visually intuitive (easy to understand or navigate visually). You can click around and quickly understand how things work. However, once you learn the Command Line Interface (CLI), it often becomes faster and more efficient for many tasks.

A CLI works through typed commands instead of visual elements. It may feel difficult at first because you need to remember commands, but with practice, it becomes a powerful tool.

---

## CLI vs GUI

### Graphical User Interface (GUI)
- Uses windows, icons, buttons, and menus  
- Easy for beginners  
- Requires mouse interaction  
- Slower for repetitive tasks  

### Command Line Interface (CLI)
- Uses text-based commands  
- Requires learning and practice  
- Faster for repeated actions  
- Can be fully controlled using the keyboard  

---

## Why Learn CLI ?

At the beginning, CLI may seem complicated compared to GUI. However, it provides speed and control once you understand how to use it.

For example, if you want to check your IP address :
- In GUI : You need to open multiple settings and navigate through menus  
- In CLI : You simply type ipconfig and press Enter  

If you need to check it again, you just repeat the same command instead of navigating again.

---

## Advantages of CLI

### 1. Lower Resource Usage
CLI programs use very little system memory and processing power compared to graphical applications.

This makes CLI useful for :
- Older computers  
- Systems with limited memory  
- Cloud environments where lower resource usage reduces cost  

### 2. Automation
CLI allows you to automate tasks easily.

You can :
- Write batch files (`.bat`)  
- Create scripts to repeat commands  

This is useful for tasks that you perform regularly, such as backups or system checks.

### 3. Remote Management
CLI is very useful for managing systems remotely.

Using tools like SSH, you can control :
- Servers  
- Network devices (routers, switches)  
- IoT devices  

CLI works well even on slow internet connections and systems with limited resources.

### 2. Network Troubleshooting

Networking problems are common, and Windows provides several built-in command-line tools to diagnose them quickly.

These tools help answer important questions :

- Can I reach another system?
- What route does my traffic take?
- Is DNS working properly?
- Which connections are currently active?

#### i. ping

The ping command tests connectivity between your computer and another host.

```
ping example.com
```

<img width="550" height="250" alt="image" src="https://github.com/user-attachments/assets/042b96d5-20be-4176-911b-d34b30d701c3" />
<br>

**How It Works ?**
- Sends ICMP Echo Request packets
- Waits for ICMP Echo Replies
- Measures response time

**Information Provided**
- Target IP address
- Response time (latency)
- Packet loss
- TTL (Time To Live)
If replies are received, communication is successful.

**Common Uses**
- Verify internet connectivity
- Test if a host is online
- Measure network latency
- Identify packet loss

**Key Points**
- Successful replies mean the host is reachable.
- Packet loss may indicate network issues.
- High latency can suggest congestion or distance.

#### 2. tracert 

The tracert command displays the route packets take to reach a destination.
```
tracert example.com
```
> Note : In Linux, the command for tracing network paths is traceroute, whereas tracert is exclusively used on Windows.

<img width="650" height="500" alt="image" src="https://github.com/user-attachments/assets/5eb29b49-71e5-46a3-a4ab-3889e9479b97" />
<br>

**How It Works ?**
- Sends packets with gradually increasing TTL values.
- Each router decreases the TTL by one.
- When TTL reaches zero, the router responds.
This reveals every hop between your system and the destination.

**Information Provided**
- Each router along the path
- Response time for every hop
- Total hop count

**Common Usage** 
- Identifies routing problems.
- Locates slow network segments.
- Helps determine where a connection fails.
Asterisks (*) usually mean the router does not respond to ICMP requests. This is common and not always an issue.

## Task and Process Management

Windows allows you to monitor and control running programs directly from the command line.

This is especially useful when :

- A program becomes unresponsive
- You need to identify running processes
- You want to terminate a specific task
- Performing system enumeration

---

## Viewing Running Processes

To display all active processes:

```
tasklist
```

<img width="650" height="350" alt="image" src="https://github.com/user-attachments/assets/e0da6ba7-3bcb-4511-a63c-1be1701c686f" />
<br>

## Understanding Important Columns

| Column | Description |
|---------|-------------|

| Mem Usage | Amount of RAM being used |

## Filtering Processes

Instead of viewing every process, you can search for a specific one.

### Example

```
tasklist /FI "imagename eq sshd.exe"
```

<img width="800" height="150" alt="image" src="https://github.com/user-attachments/assets/6742a30b-8f0d-48d9-8bd2-be8c17ff08ee" />
<br>

### Why Filtering Is Useful ? 

- Quickly locate a process
- Reduce clutter
- Find duplicate instances
- Confirm whether a service is running

---

## Viewing Help

To see all available options:
```
tasklist /?
```
This displays supported filters and syntax.

---

## Terminating Processes

Once you know a process ID, you can stop it.

### Syntax
```
taskkill /PID <PID>
```
### Example
```
taskkill /PID 4567
```
---

## How It Works

- Identifies the process by PID
- Sends a termination signal
- Stops the program immediately

## Why Use PID ?

- Multiple processes may have the same name.
- Using the PID ensures you terminate the correct one.

---

## Workflow

1. Find the target process
   
```
tasklist /FI "imagename eq notepad.exe"
```

2. Note its PID

3. Terminate it
   
```
taskkill /PID 1234
```

---

### Summary 

| Command | Purpose |
|---------|---------|
| tasklist | Display all running processes |
| tasklist /FI "imagename eq name.exe" | Filter processes by name |
| tasklist /? | Show help and available filters |
| taskkill /PID PID | Terminate a process by PID |

### Key Takeaway

Process management is essential for:

- Troubleshooting frozen applications
- Monitoring system activity
- Identifying suspicious programs
- Managing services efficiently

Understanding `tasklist` and `taskkill` gives you full command-line control over running processes.

## Additional Useful Commands

There are many Windows command-line tools beyond the basics. While not essential for beginners, these commands are extremely useful for system maintenance and troubleshooting.

### 1. chkdsk

Checks disks for errors and bad sectors.

```
chkdsk
```
### What It Does ? 

- Scans the file system
- Detects disk errors
- Identifies bad sectors
- Reports disk health

Useful when you suspect storage issues.

### 2. driverquery

Displays installed device drivers.

```
driverquery
```
### What It Shows ? 

- Driver names
- Module names
- Installation details

Helpful for :

- Driver troubleshooting
- System enumeration
- Compatibility checks

### 3. sfc /scannow

Scans and repairs Windows system files.

```
sfc /scannow
```

### What It Does ?

- Verifies system file integrity
- Replaces corrupted files
- Restores missing protected files

Very useful when Windows behaves unexpectedly.

### 4. Getting Help

Most Windows commands support a built-in help page.

Syntax

```
command /?
```

Example : 

```
tasklist /?
```

This displays :

- Command syntax
- Available options
- Usage examples

Whenever you encounter a new command, this should be your first step.

### 5. Using more

The more command helps manage long output.

### View Large Text Files

```
more file.txt
```
Displays the file one page at a time.

### 6. Paginate Command Output

```
some_command | more
```
Example :
```
systeminfo | more
```

### Navigation Controls

- Space : Next page
- Enter : Next line
- Ctrl + C : Exit

### Summary Table

| Command | Purpose |
|---------|---------|
| chkdsk | Check disks for errors |
| driverquery | List installed device drivers |
| sfc /scannow | Scan and repair system files |
| command /? | Display command help |
| more file.txt | View large text files |
| command \| more | Paginate lengthy command output |

### Key Takeaway

You do not need to memorize every Windows command.

Instead, remember these two important concepts:

- Use command /? to learn any command.
- Use | more when output is too long to read comfortably.

These two techniques will help you explore and master new commands independently.
