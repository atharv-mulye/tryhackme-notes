# Linux Shells

## Introduction to Linux Shells

### Overview

Linux systems provide two main ways to interact with the operating system:

- Graphical User Interface (GUI)
- Command Line Interface (CLI)

Most users rely on the GUI because it is simple and visual. However, many advanced users and professionals prefer the CLI because it offers greater control, speed, and flexibility.

The shell is the program that allows users to interact with the Linux operating system through commands.

---

## What is a Shell ?

A shell is a command interpreter that takes user commands and communicates them to the operating system.

It acts as a bridge between:
- The user
- The Linux kernel

When a command is entered in the terminal, the shell processes it and tells the operating system what to do.

---

## GUI vs CLI

### GUI (Graphical User Interface)

The GUI allows users to:
- Click icons
- Open menus
- Drag and drop files

It is user-friendly but may require more system resources.

Examples:
- File Explorer

- Settings applications

### CLI (Command Line Interface)

The CLI allows users to perform tasks by typing commands.

Advantages:
- Faster execution
- Better automation
- More control over the system
- Lower resource usage

CLI is widely used by:
- System administrators
- Developers
- Ethical hackers
- Cyber security professionals

## Changing the Default Shell

To permanently change the default shell, Linux uses the `chsh` command.

### Syntax

```bash
chsh -s <shell_path>
```

## Example

```bash
chsh -s /usr/bin/zsh
```

> If you want to permanently change your default shell, you can use the command : chsh -s /usr/bin/zsh. This will make this shell as the default shell for your terminal.

### Explanation

- `chsh` means **change shell**
- `-s` specifies the new shell path

After logging in again, the selected shell becomes the default.

## The Locker Script

### Overview

This task combines important shell scripting concepts into one practical example.

The script checks for the following details:

|---|---|

## Script Breakdown

### 1. Shebang

```bash
#!/bin/bash
```

Defines Bash as the script interpreter.

### 2. Variables

```bash
username=""
companyname=""
pin=""
```

Variables are created to store:
- Username
- Company name
- PIN

These values will later be compared during authentication.

### 3. Loop

```bash
for i in {1..3}; do
```

The loop runs three times.

Each iteration asks for different information:
1. Username
2. Company name
3. PIN

### 4. Conditional Statements Inside Loop

The script checks the loop number using:

```bash
if [ "$i" -eq 1 ]
```

#### Conditions Used

| Condition | Action |
|---|---|
| `i = 1` | Ask for username |
| `i = 2` | Ask for company name |
| Else | Ask for PIN |

### 5. User Input

```bash
read username
```

The `read` command stores user input into variables.

### 6. Authentication Check

```bash
if [ "$username" = "John" ] && [ "$companyname" = "Tryhackme" ] && [ "$pin" = "7385" ]
```

The script checks:
- Username matches
- Company name matches
- PIN matches

The `&&` operator means:
- ALL conditions must be true
