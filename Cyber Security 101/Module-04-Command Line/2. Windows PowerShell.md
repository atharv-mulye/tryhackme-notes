# PowerShell 

## What is PowerShell ?

PowerShell is a command-line shell and scripting language developed by Microsoft for:

- System administration
- Task automation
- Configuration management
- Cyber security operations

It combines :
- A command-line interface (CLI)
- A scripting language
- Automation tools

PowerShell is more advanced than the traditional Windows Command Prompt (`cmd.exe`).

---

## Why PowerShell is Powerful ? 

Traditional command-line tools mostly work with plain text.

PowerShell works with objects.

An object contains :
- Properties → data/information
- Methods → actions/functions

Example :
A file object can contain:
- File name
- Size
- Creation date

And actions like :
- Copy
- Delete
- Move

Because PowerShell passes objects between commands, it allows :
- Better automation
- Easier filtering
- Advanced data handling
- More control over Windows systems

This approach is called object-oriented.

---

## Why PowerShell Was Created ? 

Older Windows tools like :
- `cmd.exe`
- Batch scripts

were limited for large enterprise environments.

Microsoft created PowerShell to :
- Improve automation
- Manage complex systems
- Interact with Windows APIs
- Simplify administration tasks

---

## Cross-Platform Support

PowerShell originally worked only on Windows.

Modern PowerShell (PowerShell Core) now supports :
- Windows
- Linux
- macOS

## Piping, Filtering, and Sorting Data in PowerShell

### Overview

PowerShell supports piping, which allows the output of one command to become the input of another command.

The pipe symbol :

```powershell
|
```

Unlike traditional command-line shells that pass plain text, PowerShell passes objects. These objects contain useful properties and methods, making data processing more powerful and flexible.

---

## Using the Pipeline

A pipeline connects multiple cmdlets together.

## Example: Sorting Files by Size

```powershell
Get-ChildItem | Sort-Object Length
```

<img width="800" height="200" alt="image" src="https://github.com/user-attachments/assets/6994460d-d178-482b-9a1d-0efe05a56031" />

### Explanation

- `Get-ChildItem` retrieves files and folders.
- The pipe (`|`) sends the objects to the next cmdlet.
- `Sort-Object Length` sorts the results using the `Length` property.

This displays files ordered by size.

---

## Filtering Data with Where-Object

`Where-Object` filters objects based on conditions.

### Example : Show Only `.txt` Files


### Explanation

- `Extension` checks the file extension.
- `-eq` means "equal to".
- Only files ending in `.txt` are displayed.

## Building Longer Pipelines

PowerShell pipelines can contain multiple cmdlets together.

### Example : Find the Largest File

```powershell
Get-ChildItem |
Sort-Object Length -Descending |
Select-Object -First 1
```

### Explanation

1. `Get-ChildItem` gets all files.
2. `Sort-Object Length -Descending` sorts largest to smallest.
3. `Select-Object -First 1` returns only the biggest file.

## PowerShell Scripting

### Overview

Scripting is the process of writing multiple commands inside a text file so they can run automatically.

Instead of typing commands one by one manually, a script allows the computer to execute tasks in sequence.

PowerShell scripts usually use the `.ps1` file extension.

Example:

```text

```

---

Scripting helps to:

- Automate repetitive tasks
- Save time
- Reduce human errors
- Manage systems efficiently
- Perform complex operations quickly

A script works like a checklist for the computer, where each line contains an instruction to execute.

## Invoke-Command

`Invoke-Command` is one of the most powerful PowerShell cmdlets.

It allows commands or scripts to run on remote systems.

### Syntax

```powershell
Invoke-Command
```

---

## Running a Script on a Remote Machine

### Example

```powershell
Invoke-Command -FilePath "C:\scripts\test.ps1" -ComputerName Server01
```

### Explanation

- `-FilePath` specifies the local script.
- `-ComputerName` specifies the remote system.
- The script executes remotely.

This is useful for automating administration across multiple computers.

---

## Running Commands Remotely

### Example

```powershell
Invoke-Command -ComputerName Server01 -ScriptBlock { Get-Process }
```

### Explanation

- `-ScriptBlock { }` contains the command to execute remotely.
- `Get-Process` runs on the remote machine.
- Results are returned to the local terminal.

This works similarly to opening PowerShell directly on the remote computer.

---

## Using Credentials

Remote execution may require authentication.

### Example

```powershell
Invoke-Command -ComputerName Server01 -Credential Domain\User -ScriptBlock { Get-Service }
```

### Explanation

- `-Credential` specifies a user account.
- PowerShell prompts for the password.
- Commands run with that user's permissions.
