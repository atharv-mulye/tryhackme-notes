# PowerShell 

## What is PowerShell ?

PowerShell is a command-line shell and scripting language developed by Microsoft for:

- System administration
- Task automation
- Configuration management
- Cyber security operations

It combines :
- A command-line interface (CLI)
- A scripting language
- Automation tools

PowerShell is more advanced than the traditional Windows Command Prompt (`cmd.exe`).

---

## Why PowerShell is Powerful ? 

Traditional command-line tools mostly work with plain text.

PowerShell works with objects.

An object contains :
- Properties → data/information
- Methods → actions/functions

Example :
A file object can contain:
- File name
- Size
- Creation date

And actions like :
- Copy
- Delete
- Move

Because PowerShell passes objects between commands, it allows :
- Better automation
- Easier filtering
- Advanced data handling
- More control over Windows systems

This approach is called object-oriented.

---

## Why PowerShell Was Created ? 

Older Windows tools like :
- `cmd.exe`
- Batch scripts

were limited for large enterprise environments.

Microsoft created PowerShell to :
- Improve automation
- Manage complex systems
- Interact with Windows APIs
- Simplify administration tasks

---

## Cross-Platform Support

PowerShell originally worked only on Windows.

Modern PowerShell (PowerShell Core) now supports :
- Windows
- Linux
- macOS

## PowerShell — Basics 

### Launching PowerShell

PowerShell can be opened in multiple ways on Windows :

- Start Menu → Search powershell
- Run Dialog → Win + R → type powershell
- File Explorer → type powershell in address bar
- Command Prompt → type :

```powershell
powershell
```

After launching, the prompt looks like:

```powershell
PS C:\Users\User>
```

`PS` indicates PowerShell.

---

## Cmdlets

PowerShell commands are called cmdlets.

Cmdlets follow the format :

```powershell
Verb-Noun
```

Examples :

```powershell
Get-Content
Set-Location
Get-Process
```

- Verb → action
- Noun → target/object

---

## Common Cmdlets

### Get-Command

Displays available commands, functions, aliases, and scripts.

```powershell
Get-Command
```

Filter by command type :

```powershell
Get-Command -CommandType Function
```

---

### Get-Help

Shows help information for cmdlets.

```powershell
Get-Help Get-Date
```

Useful options :

```powershell
Get-Help Get-Date -examples
Get-Help Get-Date -detailed
Get-Help Get-Date -full
```

---

## Aliases

PowerShell includes aliases for common commands.

Examples :

| Alias | Actual Cmdlet |
|---|---|
| `dir` | `Get-ChildItem` |
| `cd` | `Set-Location` |
| `cat` | `Get-Content` |
| `clear` | `Clear-Host` |

View aliases :

```powershell
Get-Alias
```

---

## Modules

Modules are collections of cmdlets.

PowerShell can download additional modules from online repositories.


### Find Modules

```powershell
Find-Module -Name "PowerShell*"
```

`*` acts as a wildcard.

### Install Modules

```powershell
Install-Module -Name "PowerShellGet"
```

This installs new PowerShell functionality.

---

## Important Concepts

### Cmdlets
PowerShell commands are called cmdlets.

### Verb-Noun Structure
Makes commands easier to understand and remember.

### Aliases
Shortcuts for cmdlets.

### Modules
Packages containing additional cmdlets and functions.

### Wildcard (`*`)
Used for pattern matching.

Example :

```powershell
Find-Module -Name "PowerShell*"
```

Matches anything starting with `PowerShell`.
