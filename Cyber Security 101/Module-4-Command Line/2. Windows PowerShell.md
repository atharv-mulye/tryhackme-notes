# PowerShell 

## What is PowerShell ?

PowerShell is a command-line shell and scripting language developed by Microsoft for:

- System administration
- Task automation
- Configuration management
- Cyber security operations

It combines :
- A command-line interface (CLI)
- A scripting language
- Automation tools

PowerShell is more advanced than the traditional Windows Command Prompt (`cmd.exe`).

---

## Why PowerShell is Powerful ? 

Traditional command-line tools mostly work with plain text.

PowerShell works with objects.

An object contains :
- Properties → data/information
- Methods → actions/functions

Example :
A file object can contain:
- File name
- Size
- Creation date

And actions like :
- Copy
- Delete
- Move

Because PowerShell passes objects between commands, it allows :
- Better automation
- Easier filtering
- Advanced data handling
- More control over Windows systems

This approach is called object-oriented.

---

## Why PowerShell Was Created ? 

Older Windows tools like :
- `cmd.exe`
- Batch scripts

were limited for large enterprise environments.

Microsoft created PowerShell to :
- Improve automation
- Manage complex systems
- Interact with Windows APIs
- Simplify administration tasks

---

## Cross-Platform Support

PowerShell originally worked only on Windows.

Modern PowerShell (PowerShell Core) now supports :
- Windows
- Linux
- macOS

## PowerShell — Basics 

### Launching PowerShell

PowerShell can be opened in multiple ways on Windows :

- Start Menu → Search powershell
- Run Dialog → Win + R → type powershell
- File Explorer → type powershell in address bar
- Command Prompt → type :

```powershell
powershell
```

After launching, the prompt looks like:

```powershell
PS C:\Users\User>
```

`PS` indicates PowerShell.

## Cmdlets

PowerShell commands are called cmdlets.

Cmdlets follow the format :

```powershell
Verb-Noun
```

Examples :

```powershell
Get-Content
Set-Location
Get-Process
```

- Verb → action
- Noun → target/object

## Modules

Modules are collections of cmdlets.

PowerShell can download additional modules from online repositories.


### Find Modules

```powershell
Find-Module -Name "PowerShell*"
```

`*` acts as a wildcard.

### Install Modules

```powershell
Install-Module -Name "PowerShellGet"
```

This installs new PowerShell functionality.

---

## Important Concepts

### Cmdlets
PowerShell commands are called cmdlets.

### Verb-Noun Structure
Makes commands easier to understand and remember.

### Aliases
Shortcuts for cmdlets.

### Modules
Packages containing additional cmdlets and functions.

### Wildcard (`*`)
Used for pattern matching.

Example :

```powershell
Find-Module -Name "PowerShell*"
```

Matches anything starting with `PowerShell`.

## Navigating the File System and Working with Files in PowerShell

### Overview
PowerShell provides cmdlets to manage files and directories efficiently. Unlike Command Prompt, where different commands are used for different tasks, PowerShell keeps things consistent with reusable cmdlets.

---

## Listing Files and Directories

`Get-ChildItem` displays files and folders inside a directory.

Similar commands :
- `dir` in CMD
- `ls` in Linux

### Syntax

```powershell
Get-ChildItem
```

<img width="800" height="300" alt="image" src="https://github.com/user-attachments/assets/2ab93720-0974-4aef-95b0-66913f838767" />

### Example

```powershell
Get-ChildItem -Path "C:\Users\captain"
```

This shows all files and folders inside the specified path.

---

## Changing Directories

`Set-Location` changes the current working directory.

Equivalent CMD command:
```cmd
cd
```

### Syntax

```powershell
Set-Location -Path "<directory>"
```

<img width="700" height="60" alt="image" src="https://github.com/user-attachments/assets/7eb703d0-aafb-4431-9f9c-390c77bc6a80" />

### Example

```powershell
Set-Location -Path ".\Documents"
```

This moves the terminal into the `Documents` folder.

---

## Creating Files and Folders

`New-Item` is used to create both files and directories.

### Create a Directory

```powershell
New-Item -Path ".\captain-cabin" -ItemType Directory
```

### Create a File

```powershell
New-Item -Path ".\captain-cabin\captain-log.txt" -ItemType File
```

This creates an empty text file.

## Copying Files and Directories

`Copy-Item` creates a duplicate of a file or folder.

### Example

```powershell
Copy-Item -Path ".\captain-hat.txt" -Destination ".\captain-hat-copy.txt"
```

<img width="800" height="200" alt="image" src="https://github.com/user-attachments/assets/dfa875c6-5292-4284-8002-efaa09409671" />

This copies the file with a new name.

## Moving Files and Directories

`Move-Item` transfers files or folders to another location.

### Example

```powershell
Move-Item -Path ".\captain-hat.txt" -Destination ".\storage\captain-hat.txt"
```

This moves the file into the `storage` folder.
