# Windows Command Line 

## Introduction

Most users prefer a Graphical User Interface (GUI) because it is easy to use and visually intuitive (easy to understand or navigate visually). You can click around and quickly understand how things work. However, once you learn the Command Line Interface (CLI), it often becomes faster and more efficient for many tasks.

A CLI works through typed commands instead of visual elements. It may feel difficult at first because you need to remember commands, but with practice, it becomes a powerful tool.

---

## CLI vs GUI

### Graphical User Interface (GUI)
- Uses windows, icons, buttons, and menus  
- Easy for beginners  
- Requires mouse interaction  
- Slower for repetitive tasks  

### Command Line Interface (CLI)
- Uses text-based commands  
- Requires learning and practice  
- Faster for repeated actions  
- Can be fully controlled using the keyboard  

---

## Why Learn CLI ?

At the beginning, CLI may seem complicated compared to GUI. However, it provides speed and control once you understand how to use it.

For example, if you want to check your IP address :
- In GUI : You need to open multiple settings and navigate through menus  
- In CLI : You simply type ipconfig and press Enter  

If you need to check it again, you just repeat the same command instead of navigating again.

---

## Advantages of CLI

### 1. Lower Resource Usage
CLI programs use very little system memory and processing power compared to graphical applications.

This makes CLI useful for :
- Older computers  
- Systems with limited memory  
- Cloud environments where lower resource usage reduces cost  

### 2. Automation
CLI allows you to automate tasks easily.

You can :
- Write batch files (`.bat`)  
- Create scripts to repeat commands  

This is useful for tasks that you perform regularly, such as backups or system checks.

### 3. Remote Management
CLI is very useful for managing systems remotely.

Using tools like SSH, you can control :
- Servers  
- Network devices (routers, switches)  
- IoT devices  

CLI works well even on slow internet connections and systems with limited resources.

## Basic System Information 

### Understanding Command Execution (PATH)
Before running commands in Windows Command Prompt, it's important to understand how the system finds them.
- Windows uses the PATH environment variable to locate executable files.
- You can view environment variables using :

<img width="1907" height="793" alt="image" src="https://github.com/user-attachments/assets/fa09de39-bf0c-4ce7-b8ab-d07da51bff49" />

**Command :** set
- The `Path=` entry shows directories where Windows searches for commands.
- Each directory is separated by a semicolon `;`.

**Key Idea :**  
If a command is inside one of these directories, you can run it directly. Otherwise, you must provide the full path.

**Command :** systeminfo

## Handling Long Output (Paging)
Some commands produce long outputs that scroll too quickly.

<img width="629" height="454" alt="image" src="https://github.com/user-attachments/assets/a5c38637-4c02-4f98-a2a3-687e04a7661f" />

Use `more` to paginate output :
Example : driverquery | more

- Shows output page by page
- Press Spacebar : Next page  
- Press Ctrl + C : Exit  

## Useful Basic Commands

**Command :** help
- Displays available commands or detailed help for a specific command.
- Example : help systeminfo

**Command :** cls
- Clears the Command Prompt screen.
- Helps keep the terminal clean.

## Summary
- `set` → View environment variables (including PATH)
- `ver` → Check Windows version
- `systeminfo` → Detailed system info
- `| more` → Paginate long outputs
- `help` → Get command help
- `cls` → Clear screen

These commands are fundamental for understanding and enumerating a Windows system.
