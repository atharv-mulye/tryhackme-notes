# Hydra

## What is Hydra ?

**Hydra** is a fast online password auditing and authentication testing tool.

It automates login attempts against supported services by trying usernames and passwords from wordlists, making it useful for **authorized security testing** of authentication systems.

> Hydra is a brute force online password cracking program, a quick system login password “hacking” tool.

---

## Purpose of Hydra

Instead of manually testing credentials:

```text
admin : password
admin : admin123
admin : qwerty
```

Hydra can automatically test many username/password combinations against a target service.

---

## How Hydra Works ? 

Basic workflow:

```text
Username List
       +
Password List
       ↓
     Hydra
       ↓
Target Service
       ↓
Successful Login Found
```

Hydra systematically tests credentials until:

- A valid login is found.
- The wordlist is exhausted.
- The process is stopped.

## Supported Protocols

Hydra supports many authentication services, including:

### Remote Access

- SSH (Secure Shell is a cryptographic network protocol used to securely access, manage, and command a remote computer over an unsecured network)
- Telnet (Teletype Network is an old terminal emulation protocol used to log into and manage remote computers via a text-based command-line interface)
- RDP (Remote Desktop Protocol is a proprietary network protocol developed by Microsoft that allows a user to graphically interface with and control another computer over a network connection)
- VNC (Virtual Network Computing is a graphical desktop-sharing protocol used to remotely control another computer over a network connection)

### File Transfer

- FTP (File Transfer Protocol is a standard network protocol used to transfer files between a client and a server over a computer network)
- AFP (Apple Filing Protocol is a proprietary network file-sharing protocol developed by Apple for connecting macOS computers and sharing files over a local network)

### Email Services

- SMTP (Simple Mail Transfer Protocol is the standard network protocol used to send and transmit email messages across the internet)
- POP3 (Post Office Protocol version 3 is an application-layer network protocol used by email clients to retrieve and download emails from a remote mail server to a local device)
- IMAP (Internet Message Access Protocol is the standard network protocol used by email clients to access and manage email messages stored on a remote mail server)

### Databases

- MySQL
- PostgreSQL
- MongoDB
- MS-SQL
- Oracle

### Web Applications

- HTTP Basic Authentication
- HTTP Forms (GET/POST)
- HTTPS Forms

### Network Services

- LDAP (Lightweight Directory Access Protocol is a network protocol used to store, manage, and search information about users, devices, and passwords in a central directory)
- SNMP (Simple Network Management Protocol is an application-layer protocol used to monitor, manage, and configure network devices over an IP network)
- SMB (Server Message Block is a network file-sharing protocol used to share access to files, printers, serial ports, and communications between nodes on a network)
- SIP (Session Initiation Protocol is an application-layer signaling protocol used to create, modify, and terminate real-time multimedia sessions over an IP network)

## Password Security Lesson

Hydra demonstrates why weak passwords are dangerous.

### Weak Password Examples

```text
password
123456
admin
qwerty
welcome
```

These often appear in public password wordlists.

---

### Strong Password Characteristics

- Long length (12+ characters)
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Example:

```text
M7!qX9@Lp#4vR2
```

## Common Weak Defaults

Many devices and applications ship with default credentials:

```text
admin : admin
admin : password
root : root
```

Examples:

- CCTV Cameras
- Routers
- IoT Devices
- Web Applications
- Network Appliances

These should always be changed immediately.

### What Does "Hydra Supports Many Protocols" Mean ?

- Hydra does **not crack encryption or hack protocols**.
- It automates login attempts using the normal authentication process.
- "Supports a protocol" means Hydra knows how to communicate with that service and test credentials.

#### Examples

- **SSH** → Tries SSH usernames/passwords.
- **FTP** → Tries FTP logins.
- **SMB** → Tries Windows share credentials.
- **RDP** → Tries Remote Desktop logins.
- **MySQL/PostgreSQL** → Tries database credentials.
- **HTTP/HTTPS Forms** → Tries website login forms.

> Hydra supports many protocols = Hydra can automate password guessing against login services that use those protocols.

## Using Hydra

### What is Hydra ?
Hydra is a password brute-forcing tool used to test login services by trying many passwords automatically.

**Common use :** Testing weak passwords on services like SSH, FTP, web login forms, etc. (only on systems you are authorized to test).

---

## Basic Syntax

```bash
hydra [options] target service
```

---

## SSH Login Testing

```bash
hydra -l <username> -P <password_list> <IP> -t 4 ssh
```

### Example

```bash
hydra -l root -P passwords.txt 10.49.149.196 -t 4 ssh
```

### Options

| Option | Description |
|----------|-------------|
| `-l` | Single username |
| `-P` | Password wordlist |
| `-t` | Number of parallel threads |
| `ssh` | Target service |

### What happens ?

- Uses username `root`
- Tries every password from `passwords.txt`
- Runs 4 attempts simultaneously (more no of threads faster bruteforce attack) 
- Stops when valid credentials are found

---

## FTP Login Testing

```bash
hydra -l user -P passlist.txt ftp://10.49.149.196
```

### What happens ?

- Username = `user`
- Tries all passwords from `passlist.txt`
- Tests against FTP service

---

## Web Form (POST) Testing

### Syntax

```bash
hydra -l <username> -P <wordlist> <IP> http-post-form "<path>:<parameters>:<failure_message>" -V
```

### Example

```bash
hydra -l admin -P rockyou.txt 10.49.149.196 http-post-form "/:username=^USER^&password=^PASS^:F=incorrect" -V
```

### Parameters

| Part | Description |
|--------|-------------|
| `/` | Login page path |
| `username=^USER^` | Username field |
| `password=^PASS^` | Password field |
| `F=incorrect` | Text shown when login fails |
| `-V` | Show every attempt |

### Placeholders

| Placeholder | Replaced With |
|------------|--------------|
| `^USER^` | Username |
| `^PASS^` | Password from wordlist |

---

## Non-Default Port

```bash
hydra -l admin -P rockyou.txt 10.49.149.196 http-post-form "/:username=^USER^&password=^PASS^:F=incorrect" -s 8080 -V
```

### Option

| Option | Description |
|----------|-------------|
| `-s` | Specify custom port |

---

## Quick Workflow

1. Identify service (SSH, FTP, Web Form, etc.)
2. Find username (if known)
3. Obtain password wordlist
4. Run Hydra with correct module
5. Hydra tests passwords automatically
6. If a valid password exists in the wordlist, Hydra reports it

---

## Important Note

Hydra does **not magically crack passwords**.

It:
- Takes usernames
- Takes a password list
- Tries them automatically against a login service

Success depends on:
- Weak password being used
- Password existing in the wordlist
- No rate limiting/account lockout protection
