# Logs Fundamentals

## What are Logs ?

Logs are digital records (footprints) of activities performed by users, applications, systems, or networks.

Every action whether normal or malicious can generate a log entry.

Logs help security teams understand:

- What happened?
- When did it happen?
- Who performed it?
- Where did it happen?
- How did it happen?

> **Logs = Digital footprints of system activities.**

---

## Why are Logs Important ?

Logs help security teams detect, investigate, and troubleshoot incidents.

## Common Use Cases

| Use Case | Purpose |
|----------|---------|
| **Security Monitoring** | Detect suspicious or malicious activities in real time. |
| **Incident Investigation & Digital Forensics** | Determine what happened and perform Root Cause Analysis (RCA). |
| **Troubleshooting** | Identify and fix system or application errors. |
| **Performance Monitoring** | Monitor application and system performance. |
| **Auditing & Compliance** | Maintain activity records for legal and compliance requirements. |

---

## Types of Logs

### 1. System Logs

Record operating system events.

#### Examples

- System startup/shutdown
- Driver loading
- Hardware events
- System errors

**Used for:** OS troubleshooting and health monitoring.

---

### 2. Security Logs

Record security-related events.

#### Examples

- User logins (Authentication)
- Permission changes (Authorization)
- Security policy changes
- User account creation/deletion
- Suspicious activities

**Used for:** Incident detection and investigations.

---

### 3. Application Logs

Record events generated by applications.

#### Examples

- User actions
- Application updates
- Application errors
- Configuration changes

**Used for:** Application troubleshooting and monitoring.

---

### 4. Audit Logs

Track system and user changes for accountability.

#### Examples

- File access
- Data access
- User activity
- Policy enforcement
- System modifications

**Used for:** Compliance, auditing, and investigations.

---

### 5. Network Logs

Record incoming and outgoing network traffic.

#### Examples

- Incoming connections
- Outgoing connections
- Firewall logs
- Network traffic
- Connection attempts

**Used for:** Network monitoring and incident investigation.

---

### 6. Access Logs

Record access to resources.

#### Examples

- Web server access
- Database access
- API requests
- Application access

**Used for:** Tracking who accessed which resource.

---

# Log Analysis

**Log Analysis** is the process of examining logs to identify:

- Suspicious activities
- Errors
- Security incidents
- Performance issues

It helps answer questions like:

- Who accessed the system?
- What actions were performed?
- When did the activity occur?
- Was the activity malicious?

---

## Methods of Log Analysis

### Manual Analysis

- Human reviews log entries.
- Useful for small datasets and investigations.

### Automated Analysis

- SIEM and other security tools analyze logs automatically.
- Faster and suitable for large environments.

## Windows Event Logs Analysis

Windows records almost every system activity as Event Logs. These logs help administrators and security analysts monitor, troubleshoot, and investigate systems.

Windows provides a built-in tool called Event Viewer to view and analyze these logs.

## Windows Event Viewer

Event Viewer is the built-in Windows utility used to:

- View event logs
- Search for specific events
- Filter logs by Event ID
- Investigate system and security issues

### Open Event Viewer

```text
Start Menu → Search "Event Viewer"
```

## Main Windows Log Types

| Log | Purpose | Examples |
|------|----------|----------|
| **Application** | There are many applications running on the operating system. Any information related to those applications is logged into this file. This information includes errors, warnings, compatibility issues, etc. (Records events generated by applications) | Application errors, warnings, crashes, updates |
| **System** | The operating system itself has different running operations. Any information related to these operations is logged in the System log file. This information includes driver issues, hardware issues, system startup and shutdown information, services information, etc. (Records operating system events) | Startup/shutdown, drivers, hardware, services |
| **Security** | This is the most important log file in Windows OS in terms of security. It logs all security-related activities, including user authentication, changes in user accounts, security policy changes, etc. (Records security-related activities) | Login/logout, account changes, password resets, policy changes |

> **Security Logs** are the most important for SOC analysts and incident investigations.

# Event Log Fields

Each Windows Event Log contains important information.

| Field | Description |
|--------|-------------|
| **Description** | Detailed explanation of the event |
| **Log Name** | Log category (Application, System, Security, etc.) |
| **Logged** | Date and time the event occurred |
| **Event ID** | Unique identifier for a specific event type |

---

# Windows Event IDs

Every Windows activity has a unique **Event ID**.

Instead of searching thousands of logs manually, analysts search by **Event ID**.

---

# Common Windows Security Event IDs

| Event ID | Description |
|----------|-------------|
| **4624** | Successful user login |
| **4625** | Failed login attempt |
| **4634** | User logged off |
| **4720** | User account created |
| **4722** | User account enabled |
| **4724** | Password reset attempted |
| **4725** | User account disabled |
| **4726** | User account deleted |

# Filtering Logs

Event Viewer provides a **Filter Current Log** option.

### Steps

1. Open **Event Viewer**.
2. Select a log (e.g., **Security**).
3. Click **Filter Current Log**.
4. Enter the desired **Event ID** (e.g., `4624`).
5. Click **OK**.

Only matching events will be displayed.

---

# Example

### Find Successful Logins

```
Event ID: 4624
```

Filter the Security log using **4624** to display all successful login events.
