# Digital Forensics Fundamentals

## Introduction to Digital Forensics

Digital Forensics is the branch of forensics that focuses on investigating cyber crimes by collecting, preserving, analyzing, and presenting digital evidence.

A cyber crime is any crime committed using or against digital devices such as computers, smartphones, servers, or networks.

The primary goal of digital forensics is to find digital evidence that can help identify what happened, who did it, how it happened, and support legal proceedings.

---

## What is Digital Evidence ?

Digital evidence is any information stored or transmitted in digital form that can be used during an investigation.

### Examples

- Emails
- Documents
- Images
- Videos
- Chat messages
- Browser history
- System logs
- Call records
- USB files
- Hard drive data

---

## Objectives of Digital Forensics

- Collect digital evidence safely
- Preserve evidence without modification
- Analyze evidence
- Reconstruct events
- Identify the attacker
- Support legal investigations and court proceedings

---

## Example Scenario

A bank robbery suspect is arrested, and law enforcement seizes several digital devices:

- Laptop
- Mobile phone
- Hard drive
- USB drive

The Digital Forensics team investigates these devices and finds:

| Device | Evidence Found |
|---------|----------------|
| Laptop | Digital map of the bank |
| Hard Drive | Escape routes and security plans |
| Laptop | Photos and videos of previous robberies |
| Mobile Phone | Chat messages and call records related to the robbery |

These findings help investigators understand:

- How the crime was planned
- Who was involved
- What evidence supports the case

## Digital Forensics Methodology (NIST)

The **National Institute of Standards and Technology (NIST)** defines a standard digital forensics process consisting of 4 phases.

## 1. Collection

**Purpose:** Collect digital evidence safely without modifying the original data.

### Activities

- Identify digital devices
- Collect evidence
- Preserve evidence integrity
- Document every collected item

### Examples of Evidence

- Computer
- Laptop
- Mobile phone
- USB drive
- Hard drive
- Memory card
- Digital camera

> **Goal:** Ensure evidence is collected securely and remains unchanged.

## 2. Examination

**Purpose:** Filter and extract only the relevant data from the collected evidence.

Collected evidence is often very large, so investigators focus only on data related to the case.

### Activities

- Filter files
- Recover deleted files
- Extract relevant data
- Organize evidence

### Example

Collected:
- 10,000 photos

Needed:
- Only photos taken on **June 5, 2024**

> **Goal:** Reduce unnecessary data before analysis.

## 3. Analysis

**Purpose:** Analyze the filtered evidence to determine what happened.

Investigators correlate evidence from different sources to reconstruct the events.

### Activities

- Correlate evidence
- Build timelines
- Identify attacker actions
- Determine root cause
- Draw conclusions

### Example

Evidence shows:

- User downloaded malware.
- Malware executed.
- Credentials were stolen.
- Sensitive data was uploaded to an external server.

> **Goal:** Reconstruct the incident step by step.

## 4. Reporting

**Purpose:** Document the investigation and findings.

The final report is shared with law enforcement or management.

### Report Includes

- Investigation methodology
- Evidence collected
- Findings
- Timeline of events
- Screenshots
- Conclusions
- Recommendations
- Executive summary

> **Goal:** Present findings clearly and support legal proceedings.

## Types of Digital Forensics

### 1. Computer Forensics

Investigates computers and laptops.

> The most common type of digital forensics is computer forensics, which concerns investigating computers, the devices most commonly used in crimes.

#### Evidence

- Files
- Browser history
- Installed software
- Logs
- USB activity

---

### 2. Mobile Forensics

Investigates smartphones and tablets.
> Mobile forensics involves investigating mobile devices and extracting evidence such as call records, text messages, GPS locations, and more.

#### Evidence

- Call logs
- SMS
- WhatsApp chats
- Photos
- GPS locations
- Contacts

---

### 3. Network Forensics

Investigates network communications.
> This area of forensics covers investigation beyond individual devices. It includes the whole network. The majority of the evidence found in networks is the network traffic logs.

#### Evidence

- Network traffic
- Packet captures (PCAP)
- Firewall logs
- IDS/IPS logs
- VPN logs

---

### 4. Database Forensics

Investigates databases for unauthorized activities.
> Many critical data is stored in dedicated databases. Database forensics investigates any intrusion into these databases that results in data modification or exfiltration.

#### Evidence

- SQL queries
- Database logs
- Modified records
- Deleted records
- Data exfiltration

---

### 5. Cloud Forensics

Investigates cloud-hosted environments.
>  Cloud forensics is the type of forensics that involves investigating data stored on cloud infrastructure. This type of forensics sometimes gets tricky for the investigators as there is little evidence on cloud infrastructures.

#### Evidence

- Cloud logs
- User activity
- Cloud storage
- Virtual machines
- Cloud audit logs

> Cloud investigations can be challenging because investigators have limited physical access to the infrastructure.

---

### 6. Email Forensics

Investigates emails involved in cyber incidents.
>  Email, the most common communication method between professionals, has become an important part of digital forensics. Emails are investigated to determine whether they are part of phishing or fraudulent campaigns.


#### Evidence

- Email headers
- Attachments
- Sender information
- Links
- Phishing emails
- Spam campaigns

## Evidence Acquisition

Evidence Acquisition is the process of collecting digital evidence while preserving its original state.

The main objective is to ensure that the evidence remains accurate, authentic, and legally admissible.

## Best Practices for Evidence Acquisition

### 1. Proper Authorization

Before collecting any digital evidence, investigators must obtain legal authorization.

This may include:

- Search warrant
- Court order
- Organization's approval
- Owner's permission

#### Why is it important ?

- Protects privacy
- Ensures legal compliance
- Makes evidence admissible in court

> **Without proper authorization, evidence may be rejected in court.**

### 2. Chain of Custody

A Chain of Custody (CoC) is a document that records every person who handled the evidence from collection until presentation in court.

Its purpose is to prove that the evidence has not been altered, lost, or tampered with.

#### Chain of Custody Records

- Evidence description
- Evidence ID
- Person who collected it
- Date and time of collection
- Storage location
- Every person who accessed it
- Date and time of each transfer

#### Example

| Evidence | Collected By | Date | Stored At |
|----------|--------------|------|-----------|
| Laptop | John | 30-Jun-2026 | Evidence Locker A |
| USB Drive | Sarah | 30-Jun-2026 | Locker B |

> **Goal:** Maintain a complete history of the evidence.

### 3. Write Blocker

A Write Blocker is a hardware or software device that allows investigators to read data from a storage device without modifying it.

Without a write blocker, simply connecting a hard drive to a forensic workstation may:

- Change timestamps
- Modify metadata
- Alter system files

This can compromise the integrity of the evidence.
#
### How it Works

```text
Hard Drive
     │
Write Blocker
     │
Forensic Workstation

✔ Read Data
✖ Block Any Write Operations
```

#### Benefits

- Prevents accidental changes
- Preserves original evidence
- Maintains evidence integrity
- Ensures evidence is legally admissible

> **Remember:** A write blocker allows **Read Only** access to evidence.

## Summary

| Practice | Purpose |
|----------|---------|
| **Proper Authorization** | Obtain legal permission before collecting evidence |
| **Chain of Custody** | Track everyone who handles the evidence |
| **Write Blocker** | Prevent modification of the original evidence during acquisition |

## Windows Forensics

## What is Windows Forensics ?

Windows Forensics is the investigation of Windows computers/laptops to collect digital evidence after a cybercrime or security incident.

During evidence collection, investigators create forensic images (exact bit-by-bit copies) of the system.

---

## Types of Windows Forensic Images

### 1. Disk Image (Non-Volatile)

A Disk Image is a bit-by-bit copy of the storage device (HDD/SSD).

#### Characteristics

- Data remains even after shutdown/restart.
- Used to analyze stored files and system data.

#### Contains

- Documents
- Images & Videos
- Installed applications
- Browser history
- Logs
- Deleted files (recoverable)
- File system metadata

> **Non-Volatile = Data persists after power off.**

### 2. Memory Image (Volatile)

A Memory Image is a snapshot of the system's RAM.

#### Characteristics

- Must be collected before shutting down or restarting the system.
- Data is lost after power off or reboot.

#### Contains

- Running processes
- Open files
- Active user sessions
- Network connections
- Running malware
- Encryption keys
- Passwords (sometimes)

> **Volatile = Data disappears after power off.**

> **Important:** Always acquire the **Memory Image first**, then the **Disk Image**.

---

## Windows Forensics Tools

| Tool | Purpose | Acquisition / Analysis |
|------|---------|------------------------|
| **FTK Imager** | Creates and views disk images | Both |
| **Autopsy** | Analyzes disk images | Analysis |
| **DumpIt** | Captures RAM (Memory Image) | Acquisition |
| **Volatility** | Analyzes memory images | Analysis |

---

## FTK Imager

**Purpose:** Disk acquisition and basic analysis.

### Features

- Creates forensic disk images
- Bit-by-bit acquisition
- Supports multiple image formats
- File preview
- Hash verification

**Use:** Acquire and examine disk images.

---

## Autopsy

**Purpose:** Open-source digital forensic analysis platform.

### Features

- Keyword search
- Deleted file recovery
- File metadata analysis
- Timeline analysis
- Extension mismatch detection
- Browser history analysis

**Use:** Detailed disk forensic investigation.

---

## DumpIt

**Purpose:** Acquire a **Memory (RAM) Image**.

### Features

- Simple command-line tool
- Creates complete memory dump
- Supports multiple dump formats

**Use:** Memory acquisition.

---

## Volatility

**Purpose:** Analyze **Memory (RAM) Images**.

### Features

- Running process analysis
- Network connection analysis
- DLL analysis
- Malware detection
- Registry analysis
- Extract passwords and encryption keys (when possible)

**Use:** Memory forensic investigation.

---

## Disk Image vs Memory Image

| Disk Image | Memory Image |
|------------|--------------|
| Stored on HDD/SSD | Stored in RAM |
| Non-Volatile | Volatile |
| Survives reboot | Lost after reboot |
| Files, browser history, logs | Running processes, open files, network connections |
| Acquired using **FTK Imager** | Acquired using **DumpIt** |
| Analyzed using **Autopsy** | Analyzed using **Volatility** |

---

## Quick Revision

- **Disk Image → Non-Volatile Storage**
- **Memory Image → Volatile RAM**
- **Acquire RAM first**, then Disk.
- **FTK Imager** → Disk Acquisition
- **Autopsy** → Disk Analysis
- **DumpIt** → Memory Acquisition
- **Volatility** → Memory Analysis

---

## Easy Memory Trick

### Images

- **Disk = Permanent**
- **Memory = Temporary**

### Tools

- **FTK** → Take Disk Image
- **Autopsy** → Analyze Disk
- **DumpIt** → Dump RAM
- **Volatility** → View RAM

## Practical Example of Digital Forensics

Digital devices store metadata, which provides valuable information during forensic investigations.

Even if the actual content is hidden or modified, metadata can reveal:

- Who created the file
- When it was created
- Which software created it
- Where a photo was taken
- Which device captured it

---

## File Metadata Analysis

When documents are created using applications like Microsoft Word, metadata is automatically stored.

Even after exporting the document to PDF, much of this metadata is often preserved.

## Viewing PDF Metadata

Tool Used:

```bash
pdfinfo DOCUMENT.pdf
```

>  you can install it using sudo apt install poppler-utils

### Example Output

```text
Creator: Microsoft Word for Office 365
Producer: Microsoft Word for Office 365
CreationDate: Wed Oct 10 21:47:53 2018
ModDate: Wed Oct 10 21:47:53 2018
Pages: 20
Encrypted: No
```

### Information We Can Obtain

- Creator application
- Producer
- Creation date
- Last modification date
- Number of pages
- Encryption status
- PDF version
- File size

> **Purpose:** Determine **who created the document, when it was created, and which software was used.**

---

## EXIF Data (Image Metadata)

**EXIF (Exchangeable Image File Format)** stores metadata inside image files. It is a standard for saving metadata to image files.

Whenever a photo is taken using a smartphone or digital camera, additional information is automatically saved.

> you can install it using sudo apt install libimage-exiftool-perl

---

## EXIF May Contain

- Camera model
- Smartphone model
- Date & time
- GPS coordinates
- ISO
- Aperture
- Shutter speed
- Focal length

---

## Viewing EXIF Data

Tool Used:

```bash
exiftool IMAGE.jpg
```

### Example Output

```text
GPS Position:
51°31'4.00"N
0°5'48.30"W
```

---

## GPS Coordinates

If GPS was enabled when the picture was taken, EXIF data may contain:

- Latitude
- Longitude

These coordinates can be searched on:

- Google Maps
- Bing Maps

Example:

```text
51°31'4.00"N 0°5'48.30"W
```

This reveals the **exact location where the photo was captured**.
