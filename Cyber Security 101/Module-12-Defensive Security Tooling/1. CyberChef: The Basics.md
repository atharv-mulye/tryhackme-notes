# CyberChef: The Basics

## What is CyberChef ?

CyberChef is a web-based tool used to perform a wide variety of data manipulation, encoding, decoding, encryption, decryption, and forensic operations.

It works using recipes, where multiple operations are executed sequentially.

It as a **Swiss Army Knife for cybersecurity**.

> CyberChef is called a "Swiss Army Knife" because it offers a wide range of tools and functionalities for data manipulation and analysis, all in one platform. Just like a Swiss Army knife has multiple tools for different purposes, CyberChef provides various operations for encoding, decoding, and transforming data, making it a versatile tool for cybersecurity tasks.

## CyberChef Interface

CyberChef consists of four main areas:

1. Operations
2. Recipe
3. Input
4. Output

<img width="1380" height="767" alt="image" src="https://github.com/user-attachments/assets/5d964ba5-84ec-46ff-b2b9-43a00c478a3a" />

### 1. Operations

Contains all available operations grouped into categories.

Examples:

- Base64 Encode/Decode
- URL Encode/Decode
- ROT13
- XOR
- AES
- RSA
- Hashing
- Extractors

A search bar helps quickly find operations.

### 2. Recipe

The Recipe is the heart of CyberChef.

It contains the sequence of operations to perform.

Features:

- Add operations
- Rearrange operations
- Configure operation options
- Save recipe
- Load recipe
- Clear recipe
- BAKE! (Execute recipe)
- Auto Bake (Automatically execute after changes)

### 3. Input

Where data is provided.

Supports:

- Typing
- Pasting
- Drag-and-drop files
- Uploading folders
- Multiple input tabs

### 4. Output

Displays the processed result.

Features:

- Save output
- Copy output
- Replace input with output
- Maximize output pane

## Thought Process

When using CyberChef, follow these steps:

1. Define your objective.
2. Provide the input data.
3. Select the required operation(s).
4. Verify whether the output matches the expected result.

If not, modify the recipe and try again.

## What is Base Encoding ?

Base encoding converts binary data into printable ASCII characters.

Examples:

- Base64
- Base58
- Base62
- Base85

It is used for data transmission and storage—not encryption.

### Base64 Example

```
Welcome -> V2VsY29tZQ==
```

Decoding:

```
V2VsY29tZQ== -> Welcome
```

---

## URL Encoding

URL encoding replaces special characters with hexadecimal values prefixed by `%`.

Examples:

| Character | Encoded |
|-----------|----------|
| : | %3A |
| / | %2F |
| . | %2E |
| = | %3D |
| # | %23 |

Example:

```
https://example.com -> https%3A%2F%2Fexample%2Ecom
```
