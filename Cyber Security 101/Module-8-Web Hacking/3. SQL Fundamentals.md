# SQL Fundamentals

## What is a Database ?

A database is an organized collection of data that can be:

- Stored
- Retrieved
- Updated
- Managed

Databases help applications store information efficiently.

### Examples

- User accounts (username, password)
- Social media posts and comments
- Online shopping orders
- Streaming watch history
- Security logs

### Real-World Example

Instagram stores:

```text
Username
Posts
Comments
Likes
Followers
```

inside databases.

There are two main types of databases:

## Relational Databases (SQL)

Relational databases store data in a structured format using:

- Tables
- Rows
- Columns

### Example

| ID | Name | Email |
|----|------|--------|
| 1 | John | john@gmail.com |
| 2 | Alice | alice@gmail.com |

### Characteristics

- Structured data
- Fixed schema
- Relationships between tables
- High accuracy

### Common Uses

- Banking systems
- E-commerce websites
- User authentication systems

### Examples

- MySQL
- MariaDB
- PostgreSQL
- Oracle Database

---

## Non-Relational Databases (NoSQL)

NoSQL databases store data in flexible formats.

### Example

```
 {
    _id: ObjectId("4556712cd2b2397ce1b47661"),
    name: { first: "Thomas", last: "Anderson" },
    date_of_birth: new Date('Sep 2, 1964'),
    occupation: [ "The One"],
    steps_taken : NumberLong(4738947387743977493)
}
```

### Characteristics

- Flexible structure
- No fixed schema
- Handles large amounts of varying data

### Common Uses

- Social media platforms
- Big data applications
- Real-time applications

### Examples

- MongoDB
- Cassandra
- Redis

---

## SQL vs NoSQL

| Feature | SQL | NoSQL |
|----------|------|--------|
| Structure | Fixed | Flexible |
| Storage | Tables | Documents/Key-Value |
| Relationships | Supported | Limited |
| Best For | Structured Data | Unstructured Data |

## Primary Key and foreign Key

## Primary Key

## What is a Primary Key ?

A primary key uniquely identifies each row in a table.

### Example

| ID | Name |
|----|------|
| 1 | John |
| 2 | Alice |

Here:

```text
ID = Primary Key
```

### Rules

- Must be unique
- Cannot be duplicated
- One primary key per table

### Real-Life Example

```text
Student Roll Number
Employee ID
Passport Number
```

---

## Foreign Key

## What is a Foreign Key ?

A foreign key links one table to another.

### Example

#### Authors Table

| ID | Author_Name |
|----|-------------|
| 1 | Kevin Mitnick |
| 2 | Bruce Schneier |

#### Books Table

| Book_ID | Book_Name | Author_ID |
|----------|-----------|-----------|
| 1 | Book A | 1 |
| 2 | Book B | 2 |

Here:

```text
Author_ID = Foreign Key
```

because it references:

```text
Authors.ID
```

### Purpose

- Creates relationships between tables
- Prevents duplicate information
- Improves database organization

## What is a DBMS ?

A DBMS is software used to manage databases.

```text

```

### Functions

- Retrieve data

- Manage permissions

### Examples

- MySQL
- MariaDB

- MongoDB

## What is SQL ?

## SQL (Structured Query Language)

SQL is the language used to interact with relational databases.

It allows users to:

- Create databases
- Create tables
- Insert data
- Retrieve data
- Update data
- Delete data

### Example

```sql
SELECT * FROM users;
```

This retrieves all records from the users table.

---

## Benefits of SQL

### Fast

SQL databases can process large amounts of data quickly.

### Example

```sql
SELECT * FROM users;
```

can return thousands of records in seconds.

---

### Easy to Learn

SQL uses simple English-like commands.

### Examples

```sql
SELECT
INSERT
UPDATE
DELETE
```

---

### Reliable

SQL databases enforce structure and data types.

### Example

If a column expects numbers:

```sql
Age = 25
```

Valid

```sql
Age = "Hello"
```

Invalid

---

### Flexible

SQL provides powerful ways to search and analyze data.

### Example

```sql
SELECT * FROM users
WHERE age > 18;
```

Returns only users older than 18.

## What are Table Statements ?

Table statements allow you to:

- Create tables

- Inspect tables

## CREATE TABLE

## Purpose

Creates a new table inside the selected database.

### Basic Syntax

```sql
CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    column3 datatype
);
```

---

## Example

```sql
CREATE TABLE book_inventory (
    book_id INT AUTO_INCREMENT PRIMARY KEY,
    book_name VARCHAR(255) NOT NULL,
    publication_date DATE
);
```

---

## Column Breakdown

### book_id

```sql
book_id INT AUTO_INCREMENT PRIMARY KEY
```

#### INT

Stores integers.

Example:

```text
1
2
3
```

#### AUTO_INCREMENT

Automatically generates IDs.

Example:

```text
Book 1 → ID 1
Book 2 → ID 2
Book 3 → ID 3
```

#### PRIMARY KEY

Uniquely identifies each row.

---

### book_name

```sql
book_name VARCHAR(255) NOT NULL
```

#### VARCHAR(255)

Stores text up to 255 characters.

Example:

```text
Android Security Internals
```

#### NOT NULL

Cannot be empty.

Valid:

```text
Android Security Internals
```

Invalid:

```text
NULL
```

---

### publication_date

```sql
publication_date DATE
```

Stores dates.

Example:

```text
2014-10-14
```

## Purpose

Displays table structure and column information.

### Syntax

```sql

```

```sql

```

## Example

```sql

```

```text
+------------------+--------------+
| Field            | Type         |
+------------------+--------------+
| book_id          | int          |
```

### Information Shown

- Data types
- Null values

# ALTER TABLE

## Purpose

Modifies an existing table.

### Common Uses

- Add columns
- Remove columns
- Rename columns
- Change data types

---

## Add New Column

### Syntax

```sql
ALTER TABLE table_name
ADD column_name datatype;
```

### Example

```sql
ALTER TABLE book_inventory
ADD page_count INT;
```

### Result

New column added:

```text
page_count
```

---

## Table Before

| book_id | book_name | publication_date |
|----------|-----------|-----------------|
| 1 | Book A | 2014-10-14 |

---

## Table After

| book_id | book_name | publication_date | page_count |
|----------|-----------|-----------------|-----------|
| 1 | Book A | 2014-10-14 | 250 |
