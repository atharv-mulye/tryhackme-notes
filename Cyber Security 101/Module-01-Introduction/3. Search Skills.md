## Evaluation of Search Results

Anyone on the internet can publish content—blogs, articles, forum posts, or even edit public pages. This means not all information online is accurate or trustworthy.

As a learner in cyber security, it’s important to critically analyze what you read instead of blindly trusting it.

### Key Factors to Evaluate Information

#### 1. Source
- Check who created the content
- Is it an expert, organization, or random individual ?
- Trusted sources are usually well-known or have proven credibility

#### 2. Evidence & Reasoning
- Are claims supported with facts, data, or references ?
- Avoid content based only on opinions without proof
- Strong arguments = logical + backed by evidence

#### 3. Objectivity & Bias
- Is the information neutral or trying to push something ?
- Watch for hidden agendas (selling products, attacking competitors, etc.)
- Good content presents facts, not just opinions

#### 4. Corroboration
- Cross-check information with multiple sources
- If several reliable sources agree → more trustworthy
- If only one source says it → be cautious

### Important Terms

- **Snake Oil** : Fake or misleading security product/method that doesn’t actually work

### Key Takeaway

- Don’t trust information blindly.
- Always verify, cross-check, and think critically before accepting anything as true.

## Search Engines

Search engines are powerful tools, but most people only use basic searches. Learning advanced search techniques helps you find more accurate and relevant results faster.

Popular search engines include :
- Google
- Bing
- DuckDuckGo

### Advanced Search Operators (Google)

Using operators can significantly improve search results.

#### 1. Exact Phrase Search
- Use quotes to search for an exact phrase  
- Example : "passive reconnaissance"
- Returns results containing the exact phrase only

#### 2. site:
- Limits results to a specific website or domain  
- Example : site:tryhackme.com success stories

#### 3. - (Exclude)
- Removes unwanted terms from results  
- Example : pyramids -tourism 
- Useful for filtering irrelevant content

#### 4. filetype:
- Searches for specific file formats (PDF, PPT, DOC, etc.)  
- Example : filetype:pdf cyber security

### Key Takeaway

Using advanced search operators helps you :
- Narrow down results
- Find specific content faster
- Avoid irrelevant information

## Vulnerabilities and Exploits

Understanding vulnerabilities and how exploits work is a key part of cyber security. There are platforms that help identify, track, and even provide exploit code for known issues.

### 1. CVE (Common Vulnerabilities and Exposures)

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/7398ffad-9043-47cd-bee9-07a7885992a7" />

- A standardized system for naming security vulnerabilities
- Each vulnerability gets a unique ID, along with the year
- Format : CVE-YYYY-XXXX
- Maintained by MITRE (MITRE Corporation is a US-based non-profit organization that operates research and development centers)
- Ensures everyone refers to the same vulnerability
- Acts like a global dictionary of security issues

### 2. NVD (National Vulnerability Database)

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/33ff6686-2d33-4e68-b1b5-418eba9cccf8" />

- A detailed database of CVEs
- Provides :
  - Severity scores (CVSS)
  - Technical details
  - Impact analysis

### 3. Exploit Database

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/383530c7-126f-4f79-9904-cfb5ce882241" />

- Collection of public exploit code
- Useful for :
  - Security testing (with permission)
  - Learning how exploits work

#### Notes :
- Some exploits are verified
- Should only be used in legal/authorized environments

### 4. GitHub

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/55805166-d870-40a2-8e9b-27cc2db20362" />

- Contains many :
  - Security tools
  - Proof-of-Concept (PoC) exploits
  - Scripts related to CVEs

#### Important:
- Not all code is safe or reliable
- Always review before using

### Key Takeaway

- CVEs help identify and track vulnerabilities
- Databases and platforms provide deeper insights and exploit code
- Always use exploit tools ethically and legally

## Technical Documentation

Technical documentation is one of the most reliable sources of information. It is usually created by the developers or official organizations behind a tool or product.

Learning how to read and use documentation is an essential skill in cyber security.

- Covers commands, system calls, and config files

#### Examples :
- Snort

- PHP

#### Why Use Official Docs ?
- Accurate and up-to-date
- Detailed explanations
- Written by the creators

### Key Takeaway

- Always prefer official documentation over random sources
- Man pages are essential for Linux users
- Documentation helps you understand tools deeply and correctly

## Social Media

Social media platforms are not just for communication - they are powerful sources of information, especially in cyber security.

They can be used for research, networking, and staying updated with the latest trends.

### Common Platforms

- Facebook
- Twitter (X)
- LinkedIn

### Why Social Media Matters in Cyber Security

#### 1. Information Gathering (OSINT)
- People often share personal details online
- This information can be used in security assessments

##### Example :
- Answers to security questions (school, pet name, etc.)
- Work-related details

#### 2. Reconnaissance

- Helps identify :
  - Employees of a company
  - Their roles and skills
  - Technologies they use

#### 3. Learning & Updates

- Follow :
  - Security experts
  - Companies
  - Cyber security groups

- Stay updated with :
  - New vulnerabilities
  - Tools and techniques
  - Industry trends

#### OPSEC Tip

- Avoid using your personal account when exploring
- Use temporary accounts/emails if needed
- Prevent unwanted connections or data exposure

#### Practical Use Cases

- **LinkedIn**
  - Best for checking professional background
  - Useful in company security assessments

- **Facebook**
  - Useful for personal information
  - Can help find answers to security questions

### Key Takeaway

Social media is a double-edged sword :
- Useful for learning and research
- Risky if people overshare sensitive information

Always think from both :
- Defender perspective (protect data)
- Attacker perspective (find weaknesses)
