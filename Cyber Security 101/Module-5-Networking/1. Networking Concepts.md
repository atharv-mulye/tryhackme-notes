# Networking 

## Introduction

- Networking is how computers talk to each other over the internet.
- Every device needs an IP address to send/receive data.
- Data does not move directly — it travels in small pieces called packets.

---

## OSI Model 

The OSI Model is a 7-layer structure that explains how data moves from one device to another.

Think of it like steps that data follows before reaching another computer.

## OSI 7 Layers 

### Layer 1 : Physical Layer
- Real hardware layer (cables, WiFi signals)
- Sends raw bits (0s and 1s)
- Examples :
  - Ethernet cable
  - Fiber optics
  - Radio signals (WiFi)

Basically : “Wires and signals”

### Layer 2 : Data Link Layer
- Communication inside the same network
- Uses MAC address
- Ensures data moves between nearby devices

Example :
- Your laptop → WiFi router in same network

Basically : “Local delivery inside a network”

### Layer 3 : Network Layer
- Moves data between different networks
- Uses IP address
- Handles routing (choosing path)

Example :
- Your device in India → Server in another country

Basically : “Finding best path across networks”

### Layer 4 : Transport Layer
- End-to-end communication between devices
- Uses :
  - TCP (reliable)
  - UDP (fast, less reliable)
- Breaks data into smaller parts and reassembles it

Basically : “Makes sure data reaches properly”

### Layer 5 : Session Layer
- Creates and manages connection between two devices
- Keeps communication active

Example :
- Login session in apps or websites

Basically : “Starts and maintains connection”

### Layer 6 : Presentation Layer
- Changes data format so system can understand it
- Handles:
  - Encryption
  - Compression
  - Encoding (ASCII, Unicode)

Example :
- Image formats like JPG, PNG

Basically : “Translates data format”

### Layer 7 : Application Layer
- What users directly interact with
- Network services used by apps

Examples :
- HTTP (websites)
- FTP (file transfer)
- DNS (domain lookup)
- Email protocols (SMTP, IMAP)

Basically : “Apps that use the internet”

---

## OSI Model Summary 

| Layer | Name | Simple Meaning | Examples |
|------|------|----------------|----------|
| 7 | Application | User services | HTTP, FTP, DNS |
| 6 | Presentation | Format data | JPEG, PNG, encryption |
| 5 | Session | Manage connection | RPC, NFS |
| 4 | Transport | End-to-end delivery | TCP, UDP |
| 3 | Network | Routing between networks | IP, ICMP |
| 2 | Data Link | Local network communication | MAC, Ethernet |
| 1 | Physical | Hardware signals | cables, WiFi |

## TCP/IP Model 

### What is TCP/IP Model ?

- TCP/IP stands for Transmission Control Protocol / Internet Protocol
- It is a real-world networking model (used in the internet today)
- Developed by the U.S. Department of Defense (DoD) in the 1970s
- Built to keep networks working even if parts fail

Simple idea : Even if some network paths are broken, data can still find another route.

### Why TCP/IP Model Exists ? 

- More practical than OSI model
- Designed for real internet communication
- Focuses on how data actually travels

### TCP/IP Layers (Top to Bottom View)

TCP/IP has 4 main layers :

### 1. Application Layer
- Combines OSI layers 5, 6, 7
- Handles user-facing network services

Examples :
- HTTP / HTTPS (web browsing)
- FTP (file transfer)
- SMTP / IMAP (email)
- SSH / Telnet (remote login)

Basically : “Apps that use the network”

### 2. Transport Layer
- Same as OSI Layer 4
- Responsible for communication between two devices
- Controls reliability and data flow

Protocols:
- TCP → reliable, slow, ordered
- UDP → fast, no guarantee

Basically : “How data is delivered between devices”

### 3. Internet Layer
- Same as OSI Layer 3
- Handles routing across networks
- Uses IP addresses to send packets

Protocols :
- IP (Internet Protocol)
- ICMP (error messages like ping)
- IPSec (security)

Basically : “Finding path across the internet”

### 4. Link Layer
- Same as OSI Layer 2 (and part of Layer 1 conceptually)
- Handles local network communication
- Works with MAC addresses and hardware

Examples :
- Ethernet (802.3)
- WiFi (802.11)

Basically : “Local device communication”

## OSI vs TCP/IP Mapping

| OSI Layer | TCP/IP Layer | Examples |
|----------|-------------|----------|
| Application (7) | Application | HTTP, FTP, SSH |
| Presentation (6) | Application | Encoding, encryption |
| Session (5) | Application | Sessions, connections |
| Transport (4) | Transport | TCP, UDP |
| Network (3) | Internet | IP, ICMP |
| Data Link (2) | Link | Ethernet, WiFi |
| Physical (1) | Link (or separate physical layer) | cables, signals |

---

## Key Differences 

### OSI Model
- Theoretical model
- 7 layers
- Used for learning and understanding

### TCP/IP Model
- Real-world model
- 4 layers (sometimes 5)
- Used in actual internet systems

---

## Key Idea 

- OSI = learning model (theory)
- TCP/IP = real internet model
- Both describe how data moves, just in different structures

---

## Key Understanding

- Application layer → user services (web, email, login)
- Transport layer → TCP/UDP communication
- Internet layer → IP routing across networks
- Link layer → local network + hardware
