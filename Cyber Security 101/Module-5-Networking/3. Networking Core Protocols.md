
# Networking Core Protocols 

## DNS (Domain Name System)

DNS translates domain names into IP addresses.

It allows users to access websites using names like:

```text
google.com
example.com
tryhackme.com
```

instead of remembering IP addresses.

---

## Purpose of DNS

Humans remember names easily.

Computers communicate using IP addresses.

DNS acts like:
```text
Internet phonebook
```

It maps:

```text
Domain Name → IP Address
```

---

## DNS Layer and Ports

DNS operates at:

```text
Application Layer (Layer 7)
```

DNS uses:

| Protocol | Port |
|---|---|
| UDP | 53 |
| TCP | 53 |

---

# Common DNS Record Types

## A Record

Maps a domain name to an IPv4 address.

Example:

```text
example.com → 172.17.2.172
```

---

## AAAA Record

Maps a domain name to an IPv6 address.

Example:

```text
example.com → IPv6 Address
```

AAAA is called:
```text
Quad-A Record
```

---

## CNAME Record

Maps one domain name to another domain name.

Example:

```text
www.example.com → example.com
```

Useful for aliases.

---

## MX Record

Specifies the mail server responsible for handling emails.

Example:

```text
example.com → mail server
```

Mail systems query MX records when sending emails.

---

# DNS Lookup Process

When you enter:

```text
www.example.com
```

your system sends a DNS query to resolve the domain name into an IP address.

The DNS server replies with:
- IPv4 address (A record)
- IPv6 address (AAAA record)

---

# nslookup Example

```bash
nslookup www.example.com
```

Output:

```bash
Name:    www.example.com
Address: 93.184.215.14
Address: 2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

---

# Output Explanation

## IPv4 Address

```text
93.184.215.14
```

Returned from:
```text
A Record
```

---

## IPv6 Address

```text
2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

Returned from:
```text
AAAA Record
```

---

# DNS Packet Capture Explanation

```bash
1 192.168.66.89 → 192.168.66.1 DNS Query A www.example.com
2 192.168.66.1 → 192.168.66.89 DNS Response A 93.184.215.14
3 192.168.66.89 → 192.168.66.1 DNS Query AAAA www.example.com
4 192.168.66.1 → 192.168.66.89 DNS Response AAAA 2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

---

# Step-by-Step Explanation

## Packet 1 — A Record Query

```bash
DNS Query A www.example.com
```

The client asks:
> "What is the IPv4 address of www.example.com?"

---

## Packet 2 — A Record Response

```bash
A 93.184.215.14
```

The DNS server replies with the IPv4 address.

---

## Packet 3 — AAAA Record Query

```bash
DNS Query AAAA www.example.com
```

The client now asks:
> "What is the IPv6 address of www.example.com?"

---

## Packet 4 — AAAA Record Response

```bash
AAAA 2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

The DNS server replies with the IPv6 address.

---

# Why Both A and AAAA Queries Exist

Modern systems support:
- IPv4
- IPv6

So devices usually request:
- A record
- AAAA record

to determine which protocol can be used.

---

# Important Notes

## DNS Uses UDP by Default

UDP is faster and suitable for small DNS queries.

---

## DNS Can Use TCP

TCP is used when:
- responses are too large
- zone transfers occur
- UDP fails

---

# Key Takeaway

DNS converts domain names into IP addresses so users can access systems using human-readable names instead of numerical IP addresses.
