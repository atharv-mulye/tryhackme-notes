# Networking Core Protocols 

## DNS (Domain Name System)

### What is DNS ?

DNS converts domain names into IP addresses.

Instead of remembering IP addresses like `93.184.215.14`, we use names like `example.com`.

DNS helps devices find the correct server on the internet.

---

## DNS Basics

- Works on the Application Layer (Layer 7) of the OSI model
- Uses:
  - **UDP Port 53** by default
  - **TCP Port 53** as fallback

---

## Common DNS Records

### A Record

Maps a domain name to an IPv4 address.

Example:

```bash
example.com -> 172.17.2.172
```

### AAAA Record

Maps a domain name to an IPv6 address.

Example:

```bash
example.com -> 2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

### CNAME Record

Maps one domain name to another domain name.

Example:

```bash
www.example.com -> example.com
```

### MX Record

Specifies the mail server for a domain.

Used when sending emails.

Example:

```bash
example.com -> mail.example.com
```

---

## DNS Query Example

When visiting a website:

```bash
www.example.com
```

The browser asks the DNS server for the:

```bash
A record
```

to get the IPv4 address.

If IPv6 is supported, it may also request the:

```bash
AAAA record
```

## Summary

- `A` record = IPv4 lookup
- `AAAA` record = IPv6 lookup
- Client sends query
- DNS server sends response
- Communication uses DNS protocol on Port 53

---

## Key Points

- DNS translates names into IP addresses
- Uses Port 53
- A = IPv4
- AAAA = IPv6
- CNAME = redirects domain names
- MX = mail server record
- `nslookup` can query DNS records

## WHOIS

### What is WHOIS ?

WHOIS is a service used to view information about a registered domain name.

When someone registers a domain, their registration details are stored in WHOIS records.

---
 
## Why WHOIS is Important ? 

The domain owner gets control over DNS records such as:

- A Record
- AAAA Record
- MX Record

This allows them to manage how the domain works.

---

## Information Found in WHOIS Records

WHOIS records may contain:

- Domain name
- Registrar company
- Creation date
- Expiration date
- Last updated date
- Owner name
- Email address
- Phone number
- Address

---

## Privacy Protection

Some domain owners use privacy protection services.

Instead of showing personal details, WHOIS may display :

```bash
Registration Private
```

or

```bash
Domains By Proxy
```

This hides the real owner information from public view.

---

## HTTP and HTTPS

### What is HTTP ?

HTTP stands for HyperText Transfer Protocol.

It is used for communication between:

- Web browser (client)
- Web server

HTTPS is the secure version of HTTP.

---

## Ports Used

| Protocol | Default Port |
|---|---|
| HTTP | 80 |
| HTTPS | 443 |

Other common ports :

- 8080
- 8443

---

## Common HTTP Methods

### GET

Retrieves data from the server.

Example:

- Opening a webpage
- Downloading an image

### POST

Sends data to the server.

Example:

- Login forms
- File uploads

### PUT

Creates or updates data on the server.

### DELETE

Removes data or files from the server.

---

## How HTTP Works

1. Browser sends a request to the web server
2. Server processes the request
3. Server sends a response back
4. Browser displays the webpage

---

## HTTP Traffic in Wireshark

Wireshark can capture communication between browser and server.

Captured data may include:

- HTTP requests
- HTTP responses
- Server version
- File information
- Last modified date

Some data is hidden from normal users but visible in packet captures.


---

## Key Points

- HTTP is used for web communication
- HTTPS is encrypted and secure
- Uses TCP protocol
- HTTP default port = 80
- HTTPS default port = 443
- GET retrieves data
- POST sends data
- Wireshark can capture HTTP traffic
- Telnet can manually communicate with web servers

---

## FTP (File Transfer Protocol)

### What is FTP ?

FTP is a protocol used to transfer files between a client and a server.

It is mainly used for:

- Uploading files
- Downloading files
- Managing files on remote servers

FTP is faster for file transfers compared to HTTP in many cases.

---

## Default Port

| Protocol | Port |
|---|---|
| FTP | 21 |

FTP uses TCP for communication.

---

## Common FTP Commands

### USER

Used to enter the username.

Example:

```bash
USER anonymous
```
### PASS

Used to enter the password.

### RETR

Downloads a file from the server.

### STOR

Uploads a file to the server.

---

## SMTP (Simple Mail Transfer Protocol)

### What is SMTP ?

SMTP is used to send emails between:

- Email client and mail server
- Mail server and another mail server

SMTP uses TCP protocol.

---

## Default Port

| Protocol | Port |
|---|---|
| SMTP | 25 |

---

## Common SMTP Commands

| Command | Purpose |
|---|---|
| HELO / EHLO | Starts SMTP session |
| MAIL FROM | Sender email address |
| RCPT TO | Recipient email address |
| DATA | Starts email content |
| . | Ends email message |
| QUIT | Closes connection |

## IMAP (Internet Message Access Protocol)

### What is IMAP ?

IMAP is used to access and synchronize emails across multiple devices.

Unlike POP3:

- POP3 downloads emails locally
- IMAP keeps emails on the server and syncs changes

Example:

- Read email on phone → also marked as read on laptop

IMAP uses TCP protocol.

---

## Default Port

| Protocol | Port |
|---|---|
| IMAP | 143 |

---

## POP3 vs IMAP

| POP3 | IMAP |
|---|---|
| Downloads emails | Syncs emails |
| Usually removes emails from server | Keeps emails on server |
| Best for one device | Best for multiple devices |

---

## Common IMAP Commands

| Command | Purpose |
|---|---|
| LOGIN | User login |
| SELECT | Select mailbox |
| FETCH | Retrieve email |
| MOVE | Move email |
| COPY | Copy email |
| LOGOUT | Close session |

- IMAP synchronizes emails across devices
- Default port = 143
- Uses TCP protocol
- Emails stay on the server
- `LOGIN` = authenticate user

## Summary

| Protocol | Purpose | Default Port | Transport Protocol |
|---|---|---|---|
| DNS | Converts domain names to IP addresses | 53 | UDP / TCP |

| FTP | Transfers files | 21 | TCP |
| SMTP | Sends emails | 25 | TCP |
| POP3 | Receives/downloads emails | 110 | TCP |
| IMAP | Synchronizes emails across devices | 143 | TCP |
