## 📌 About

This folder contains my journey through the **Cyber Security 101** path.

It provides a comprehensive introduction to cybersecurity through hands-on labs, covering operating systems, networking, cryptography, web security, exploitation, defensive security, security tools, security principles, and the **OWASP Top 10 (2025)**.

---

## 🎯 Objective

- Build a strong cybersecurity foundation
- Learn Linux, Windows, and networking fundamentals
- Understand offensive and defensive security concepts
- Gain hands-on experience with industry-standard security tools
- Learn web security and the OWASP Top 10 (2025)
