# Gobuster : The Basics

## What is Gobuster ?

Gobuster is an open-source reconnaissance and enumeration tool written in Go (Golang).

It is commonly used during:
- Reconnaissance
- Enumeration
- Scanning
- Penetration Testing
- Bug Bounty Hunting

Gobuster uses **wordlists + brute force** to discover hidden resources.

---

## Key Concepts

### Enumeration

Enumeration means discovering and listing resources that exist on a target.

Examples:
- Directories
- Files
- Subdomains
- Virtual Hosts (VHosts)
- Storage Buckets

Example:

```text
/admin
/login
/uploads
/images
```

### Brute Force

Brute force means trying every possibility until a match is found.

Gobuster:
1. Takes a wordlist
2. Tries each word
3. Checks whether the resource exists

Example wordlist:

```text
admin
login
images
uploads
```

Gobuster tests:

```text
http://target/admin
http://target/login
http://target/images
http://target/uploads
```

## Gobuster Modes

### Directory Enumeration

```bash
gobuster dir
```

Used to discover:
- Hidden directories
- Hidden files
- Admin panels
- Backup files

Example:

```bash
gobuster dir -u http://target.com -w wordlist.txt
```

### DNS Subdomain Enumeration

```bash
gobuster dns
```

Used to discover subdomains.

Examples:

```text
admin.target.com
dev.target.com
test.target.com
api.target.com
```

### Virtual Host Enumeration

```bash
gobuster vhost
```

Used to discover hidden virtual hosts hosted on the same server.

Examples:

```text
portal.target.com
internal.target.com
staging.target.com
```

### Other Modes

```text
fuzz   → Fuzzing
s3     → AWS S3 bucket discovery
gcs    → Google Cloud Storage discovery
tftp   → TFTP enumeration
```

## Important Flags

| Flag | Description |
|--------|-------------|
| `-u` | Target URL |
| `-w` | Wordlist |
| `-t` | Number of threads |
| `-o` | Save output to file |
| `--delay` | Delay between requests |
| `--debug` | Debug mode |
| `-q` | Quiet mode |

---

## Basic Syntax

```bash
gobuster <mode> -u <target> -w <wordlist>
```

Example:

```bash
gobuster dir -u http://example.thm -w small.txt
```

---

## Example Explained

```bash
gobuster dir -u http://www.example.thm/ -w /usr/share/wordlists/dirb/small.txt -t 64
```

### Breakdown

```bash
dir
```

Directory enumeration mode.

```bash
-u http://www.example.thm/
```

Target website.

```bash
-w small.txt
```

Wordlist used for brute forcing.

```bash
-t 64
```

Uses 64 concurrent threads for faster scanning.

---

## Common Workflow

1. Choose target website
2. Select enumeration mode
3. Choose wordlist
4. Run Gobuster
5. Analyze discovered resources
6. Continue testing discovered endpoints

---

## Why Pentesters Use Gobuster ? 

- Finds hidden pages
- Finds admin panels
- Finds backup files
- Finds forgotten directories
- Finds subdomains
- Expands attack surface
- Fast and easy to use
