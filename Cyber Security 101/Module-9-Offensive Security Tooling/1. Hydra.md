# Hydra

## What is Hydra ?

**Hydra** is a fast online password auditing and authentication testing tool.

It automates login attempts against supported services by trying usernames and passwords from wordlists, making it useful for **authorized security testing** of authentication systems.

> Hydra is a brute force online password cracking program, a quick system login password “hacking” tool.

---

## Purpose of Hydra

Instead of manually testing credentials:

```text
admin : password
admin : admin123
admin : qwerty
```

Hydra can automatically test many username/password combinations against a target service.

---

## How Hydra Works ? 

Basic workflow:

```text
Username List
       +
Password List
       ↓
     Hydra
       ↓
Target Service
       ↓
Successful Login Found
```

Hydra systematically tests credentials until:

- A valid login is found.
- The wordlist is exhausted.
- The process is stopped.

## Supported Protocols

Hydra supports many authentication services, including:

### Remote Access

- SSH (Secure Shell is a cryptographic network protocol used to securely access, manage, and command a remote computer over an unsecured network)
- Telnet (Teletype Network is an old terminal emulation protocol used to log into and manage remote computers via a text-based command-line interface)
- RDP (Remote Desktop Protocol is a proprietary network protocol developed by Microsoft that allows a user to graphically interface with and control another computer over a network connection)
- VNC (Virtual Network Computing is a graphical desktop-sharing protocol used to remotely control another computer over a network connection)

### File Transfer

- FTP (File Transfer Protocol is a standard network protocol used to transfer files between a client and a server over a computer network)
- AFP (Apple Filing Protocol is a proprietary network file-sharing protocol developed by Apple for connecting macOS computers and sharing files over a local network)

### Email Services

- SMTP (Simple Mail Transfer Protocol is the standard network protocol used to send and transmit email messages across the internet)
- POP3 (Post Office Protocol version 3 is an application-layer network protocol used by email clients to retrieve and download emails from a remote mail server to a local device)
- IMAP (Internet Message Access Protocol is the standard network protocol used by email clients to access and manage email messages stored on a remote mail server)

### Databases

- MySQL
- PostgreSQL
- MongoDB
- MS-SQL
- Oracle

### Web Applications

- HTTP Basic Authentication
- HTTP Forms (GET/POST)
- HTTPS Forms

### Network Services

- LDAP (Lightweight Directory Access Protocol is a network protocol used to store, manage, and search information about users, devices, and passwords in a central directory)
- SNMP (Simple Network Management Protocol is an application-layer protocol used to monitor, manage, and configure network devices over an IP network)
- SMB (Server Message Block is a network file-sharing protocol used to share access to files, printers, serial ports, and communications between nodes on a network)
- SIP (Session Initiation Protocol is an application-layer signaling protocol used to create, modify, and terminate real-time multimedia sessions over an IP network)

## Password Security Lesson

Hydra demonstrates why weak passwords are dangerous.

### Weak Password Examples

```text
password
123456
admin
qwerty
welcome
```

These often appear in public password wordlists.

---

### Strong Password Characteristics

- Long length (12+ characters)
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Example:

```text
M7!qX9@Lp#4vR2
```

---

## Common Weak Defaults

Many devices and applications ship with default credentials:

```text
admin : admin
admin : password
root : root
```

Examples:

- CCTV Cameras
- Routers
- IoT Devices
- Web Applications
- Network Appliances

These should always be changed immediately.

---

## Real-World Importance

Hydra highlights the importance of:

- Strong passwords
- Account lockout policies
- Multi-Factor Authentication (MFA)
- Rate limiting
- Monitoring failed login attempts

Without these protections, weak credentials can often be guessed quickly.
