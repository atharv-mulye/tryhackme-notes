# Active Directory Basics
      
## Introduction   

Active Directory (AD) is a directory service developed by Microsoft that is used to manage users, computers, and resources within a network. It acts as a centralized system where all identity and access-related information is stored and controlled.

In a corporate environment, AD is essential because it removes the need to manage each system individually. Instead, administrators can control authentication, permissions, and policies from a single point. 
 
### Key Purpose
- Centralized management of users and devices
- Simplified authentication across the network
- Consistent enforcement of security policies

### Core Component
- **Active Directory Domain Services (AD DS)** :  
  The main service that stores and organizes information about all objects in the network (users, computers, groups, etc.)

### Domain Controller (DC)
- A server that runs AD DS   
- Handles authentication requests
- Stores the directory database
- Enforces policies across the domain

### What You Learn in This Section
- What Active Directory is
- How domains work
- Key components of an AD environment
- Basic structure like forests and trusts (covered later)

### Prerequisite Knowledge
- Basic understanding of Windows systems
- Familiarity with user accounts and system configuration

### Key Insight
Active Directory is designed to scale. It works for both small environments and large enterprises by centralizing control and reducing manual administration.
