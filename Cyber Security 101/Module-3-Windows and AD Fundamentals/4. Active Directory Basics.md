# Active Directory Basics 

## Introduction

Active Directory (AD) is a directory service developed by Microsoft used to manage users, computers, and security within a Windows network.

It provides :
- Authentication (verifying identity)
- Authorization (controlling access)

Instead of configuring each machine individually, AD enables centralized management of an entire network.

---

## Windows Domains

### Small Network Scenario

In a small environment (e.g., 5 computers, 5 users):
- User accounts are created locally on each machine
- Configuration is done manually per system
- Troubleshooting is performed directly on each device

This approach is manageable due to the small scale.

### Large Network Scenario

In a large environment (e.g., 157 computers, 320 users, multiple locations):
- Managing each system individually becomes inefficient
- Maintaining consistent configurations is difficult
- Applying security policies manually is impractical

This leads to scalability and administrative challenges.

### Windows Domain

Windows domain is a group of users and computers under the administration of a given business.
The main idea behind a domain is to centralise the administration of common components of a Windows computer network in a single repository called Active Directory (AD). The server that runs the Active Directory services is known as a Domain Controller (DC).

A Windows Domain is a logical grouping of :
- Users
- Computers
- Resources

All managed under a centralized system.

The purpose of a domain is to :
- Centralize administration
- Standardize configurations
- Improve security management

The main advantages of having a configured Windows domain are :
- Centralised identity management : All users across the network can be configured from Active Directory with minimum effort.
- Managing security policies : You can configure security policies directly from Active Directory and apply them to users and computers across the network as needed.

## Active Directory (AD)

Active Directory is the centralized directory service that :
- Stores information about network objects (users, computers, groups)
- Provides authentication and authorization services
- Enables centralized management of resources

> In simple terms : Active Directory maintains a database of who the users are and what they are allowed to access.

## Domain Controller (DC)

A Domain Controller (DC) is a server that :
- Hosts Active Directory
- Processes authentication requests
- Enforces security policies

Key point :
- Active Directory = service
- Domain Controller = server running that service

### Key Advantages of a Windows Domain

#### Centralized Identity Management
- All user accounts are managed in one location
- Reduces duplication and administrative overhead

#### Security Policy Management
- Policies can be defined once and applied across the domain
- Ensures consistent security configuration

---

### Real-World Example

In environments like schools, universities, or offices :
- Users receive a single set of credentials
- These credentials work on any domain-joined machine

Process :
1. User logs in to a computer
2. The computer sends the authentication request to the Domain Controller
3. Active Directory verifies credentials
4. Access is granted based on permissions

### Policy Enforcement

Administrators can use Active Directory to :
- Restrict access to system settings
- Control software installation
- Assign user privileges

These policies are applied across all systems within the domain.

### Why Use a Domain

For environments with :
- Large numbers of users
- Multiple computers
- Multiple locations

A domain provides :
- Centralized control
- Scalable management
- Improved security

### Summary

- Active Directory is a directory service for centralized management
- A Domain Controller hosts and runs Active Directory
- A Windows Domain organizes users and computers into a single administrative unit

Core benefits :
- Centralized authentication
- Centralized authorization
- Consistent policy enforcement

## Active Directory Domain Services 

### Overview

The core component of a Windows Domain is Active Directory Domain Services (AD DS).

AD DS acts as a central directory database that stores information about all objects in the network.

### Common Objects in AD DS :
- Users
- Groups
- Computers (Machines)
- Printers
- Shared resources

These objects are managed centrally and used for authentication and authorization.

### Users

A User object represents an identity in the domain.

Users are classified as security principals, meaning :
- They can be authenticated (login)
- They can be assigned permissions to access resources

### Types of Users

#### 1. Human Users
- Represent real people (employees, staff)
- Used for logging into systems and accessing resources

#### 2. Service Accounts
- Used by applications or services (e.g., web servers, databases)
- Not used for interactive login
- Have limited permissions required for specific tasks

---

## Machines (Computer Objects)

Each computer that joins the domain creates a **machine object** in Active Directory.

Machines are also **security principals**, meaning:
- They have accounts
- They can authenticate within the domain

### Key Points:
- Each machine has its own account in AD
- Machine accounts have limited permissions
- They are automatically managed by the system

### Machine Account Features:
- Passwords are automatically updated
- Passwords are long and complex (typically ~120 characters)
- Not meant for manual use

### Naming Convention:
- Machine account names end with `$`

Example:
Computer Name: DC01
Machine Account: DC01$

## Security Groups

A **Security Group** is used to manage permissions efficiently.

Instead of assigning permissions to individual users, permissions are assigned to groups.

### Benefits:
- Simplifies access management
- Reduces administrative effort
- Ensures consistency

### Features:
- Can contain users
- Can contain machines
- Can contain other groups (nested groups)

### Important:
Security Groups are also **security principals**, so they can be assigned permissions.

---

## Default Security Groups

Some important built-in groups in a domain:

| Group Name          | Description |
|--------------------|------------|
| Domain Admins      | Full administrative control over the domain |
| Server Operators   | Can manage Domain Controllers (limited control) |
| Backup Operators   | Can access all files for backup purposes |
| Account Operators  | Can create and modify user accounts |
| Domain Users       | Contains all user accounts |
| Domain Computers   | Contains all computer accounts |
| Domain Controllers | Contains all Domain Controllers |

## Active Directory Users and Computers (ADUC)

**Active Directory Users and Computers (ADUC)** is a management tool used to:
- Create users
- Delete users
- Modify accounts
- Reset passwords
- Manage groups and computers

It provides a graphical interface to view and manage domain objects.

## Organizational Units (OUs)

An **Organizational Unit (OU)** is a container used to organize objects in Active Directory.

### Purpose:
- Group users and computers logically
- Apply policies to specific sets of objects

### Key Points:
- A user or computer belongs to only one OU
- OUs often reflect organizational structure (e.g., departments)
