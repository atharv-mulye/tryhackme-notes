# CIA Triad

## Introduction 

### Transition into Cyber Security
- After learning basic concepts like computers, networks, and the web, the next step is understanding how to protect them.
- Cyber security focuses on defending the digital world from threats and misuse.


### What Does Cyber Security Actually Protect ?
- Common idea : cyber security protects systems, networks, and applications.
- Deeper idea : it actually protects the data inside those systems.
- Data is the most valuable asset in the digital world.

### Why Protection is Necessary
- Most information today is stored digitally instead of on paper.
- Digital data can be :
  - Easily copied
  - Quickly modified
  - Instantly shared
- Without proper security, this creates serious risks.

### Possible Risks to Data
- **Unauthorized Access** → someone sees data they shouldn’t
- **Data Modification** → information is changed or tampered with
- **Loss of Access** → data or services become unavailable

### Core Concept : The CIA Triad
- Cyber security is built around three fundamental principles :
  - Confidentiality
  - Integrity
  - Availability

- These principles define :
  - What needs to be protected
  - How security is measured
  - How incidents are analysed

### Importance of the CIA Triad
- It provides a clear structure for understanding security
- Helps identify what went wrong during an attack
- Guides decisions to prevent future issues
- Used in almost all areas of cyber security

### Key Understanding
- Cyber security is not just about tools or hacking prevention
- It is about ensuring:
  - Data stays private (Confidentiality)
  - Data stays correct (Integrity)
  - Data is available when needed (Availability)

### Summary
- Digital data is constantly at risk
- Protecting it requires a structured approach
- The CIA Triad is the foundation of that protection

## Understanding the CIA Triad (Detailed Notes)

### What is the CIA Triad ?
- The CIA Triad is a fundamental model in cyber security.
- It defines the three main goals of protecting digital data:
  - Confidentiality
  - Integrity
  - Availability

- Security is considered effective only when all three are maintained.

### Why the CIA Triad is Important
- Digital data is constantly being stored, transferred, and accessed.
- Without proper protection, data can:
  - Be exposed to unauthorized users
  - Be modified without permission
  - Become unavailable when needed

- The CIA Triad helps identify and prevent these risks.

---

## Confidentiality

### Definition
- Ensures that data is only accessed by authorized individuals.

### Purpose
- Protect sensitive information from being seen or stolen

### How It Can Be Broken
- Weak passwords
- Sharing credentials
- Unsecured networks

### Protection Methods (Basic Idea)
- Access control (who can access data)
- Encryption (protecting data from being read)

### Examples
- Private data exposed online → NO
- Passwords written openly → NO
- Data accessible only to allowed users → YES

---

## Integrity

### Definition
- Ensures that data remains accurate and unchanged unless properly authorized.

### Purpose
- Maintain trust in the data

### How It Can Be Broken
- Unauthorized edits
- Data tampering
- Hidden changes

### Protection Methods (Basic Idea)
- Validation checks
- Controlled updates
- Monitoring changes

### Examples
- Records changed without permission → NO
- Financial data altered → NO
- Verified and approved updates → YES

---

## Availability

### Definition
- Ensures that systems and data are accessible when needed.

### Purpose
- Keep services running and usable

### How It Can Be Broken
- Server crashes
- Cyber attacks (e.g., flooding requests)
- System failures

### Protection Methods (Basic Idea)
- Backup systems
- Load handling
- System monitoring

### Examples
- Website down during work hours → NO
- Services not accessible → NO
- Systems working when needed → YES

---

## Key Comparison

| Principle        | Focus                     | Main Risk                |
|----------------|--------------------------|--------------------------|
| Confidentiality | Who can access data       | Data exposure            |
| Integrity       | Data correctness          | Data tampering           |
| Availability    | Access to systems/data    | Downtime / inaccessibility |

---

## Final Understanding
- The CIA Triad explains what cyber security protects
- Every security issue affects at least one of these :
  - Data being seen → Confidentiality issue
  - Data being changed → Integrity issue
  - Data not accessible → Availability issue

 ---

## The Security Mindset

### What is the Security Mindset?
- The CIA Triad is not just theory, it is a way of thinking in cyber security.
- Security professionals analyse every situation based on:
  - Confidentiality
  - Integrity
  - Availability

### How to Think Like a Security Professional
- When a security issue occurs, ask :
  - Was data accessed by unauthorized people ? → Confidentiality
  - Was data changed or tampered with ? → Integrity
  - Was the system or data unavailable ? → Availability

- This approach helps :
  - Identify the problem
  - Understand the impact
  - Decide the correct response
