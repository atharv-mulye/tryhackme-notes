# Cloud Computing Fundamentals

## Introduction

Cloud computing allows applications, data, and services to run on remote servers over the internet instead of on a single local computer.

This solves problems such as :
- Limited hardware capacity
- Slow performance for global users
- System downtime when a local machine turns off
- Difficulty handling many users at once

Cloud computing is built on technologies such as :
- Virtualization
- Containers

These technologies allow multiple applications to run efficiently on shared infrastructure.

---

## What is Cloud Computing ?

Cloud computing is the delivery of computing services over the internet.

These services include :
- Servers
- Storage
- Databases
- Networking
- Software
- Analytics

Instead of owning physical hardware, users rent resources from cloud providers.

This makes applications easier to :
- Deploy
- Scale
- Manage
- Access globally

---

## Evolution of Servers to Cloud

Cloud computing developed over time as organizations tried to improve efficiency and reduce costs.

### 1. Physical Servers
- One application per server
- Expensive hardware
- Low resource utilization

### 2. Virtualized Servers
- Multiple virtual machines on one server
- Better hardware utilization
- Reduced costs

### 3. Cloud Computing
- Resources delivered over the internet
- On-demand infrastructure
- Global availability
- Automatic scaling

---

## Benefits of Cloud Computing

Cloud computing provides several advantages.

### 1. Scalability
Cloud resources can increase or decrease automatically depending on demand.

Example:
A website can handle sudden traffic spikes without crashing.

### 2. On-Demand Self-Service
Users can create resources instantly without needing physical hardware.

Example : Create a new server in minutes.

### 3. Pay-As-You-Go Model
Users only pay for the resources they actually use.

This reduces :
- Initial investment
- Infrastructure costs

### 4. Security
Cloud providers implement strong security measures such as:
- Encryption
- Identity management
- Network security

### 5. High Availability
Cloud systems are designed to remain operational even if hardware fails.

This ensures :
- Minimal downtime
- Reliable services

### 6. Global Access
Applications hosted in the cloud can be accessed from anywhere in the world.

Cloud providers operate global data centers to improve performance.

---

## Types of Cloud Deployment

Cloud environments can be deployed in different ways depending on the organization's needs.

### 1. Public Cloud

A public cloud is provided over the internet and shared by multiple users.

Characteristics :
- Managed by cloud providers
- Highly scalable
- Cost-effective

Examples :
- Hosting websites
- Mobile applications
- Startups and online platforms

### 2. Private Cloud

A private cloud is dedicated to a single organization.

Characteristics :
- Higher security and control
- Custom infrastructure
- Used for sensitive data

Common users :
- Banks
- Healthcare organizations
- Government agencies

### 3. Hybrid Cloud

A hybrid cloud combines both public and private clouds.

Characteristics :
- Sensitive data stored in private cloud
- Scalable workloads run in public cloud

Example : An e-commerce company stores payment data privately but runs its website publicly.

---

## Cloud Service Models

Cloud providers offer different levels of service depending on how much control the user wants.

### 1. Infrastructure as a Service (IaaS)

In IaaS, users rent basic computing infrastructure.

Provided by the cloud provider :
- Physical servers
- Networking
- Storage
- Virtualization

User manages :
- Operating system
- Applications
- Security configuration

Examples :
- Amazon EC2
- Microsoft Azure Virtual Machines
- Google Compute Engine

### 2. Platform as a Service (PaaS)

In PaaS, the cloud provider manages the infrastructure and operating system.

Users focus only on :
- Application development
- Deployment

Advantages :
- Faster development
- No server management

Examples :
- Google App Engine
- Heroku
- AWS Elastic Beanstalk

### 3. Software as a Service (SaaS)

In SaaS, users access complete software applications through the internet.

The provider manages :
- Infrastructure
- Operating system
- Application
- Updates

Users simply use the software through a browser or app.

Examples :
- Gmail
- Zoom
- Google Docs
- Microsoft 365
