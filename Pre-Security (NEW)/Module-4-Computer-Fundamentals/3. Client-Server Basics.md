# Client-Server Basics

## Introduction
Initially, computers worked independently. They stored their own files, ran their own programs, and did not communicate with other systems.

Later, computer networks were developed to allow communication, resource sharing, and data exchange between systems. Early networks such as ARPANET, CYCLADES, NPL, and NSFNET eventually evolved into the modern Internet.

When computers started interacting over networks, they adopted a Client–Server model, where some systems request services and others provide them.

---

## Client-Server Model

The Client-Server model is a communication model where:

- A client requests a service.
- A server provides the service.

The client always initiates the request, and the server sends a response.

### Example
When you open a website:

1. Your browser (client) sends a request to a web server.
2. The web server (server) processes the request.
3. The server sends back the webpage content (HTML, CSS, JavaScript, images).

---

## Key Concepts

### Client
A client is a device or software that requests services from a server.

### Examples
- Web browsers
- Mobile apps
- Email clients

### Example
When you type a website URL into a browser, the browser acts as the client.

---

## Server
A server is a computer system that provides services or resources to clients over a network.

### Examples
- Web servers
- Database servers
- Email servers
- File servers

Servers are usually designed to handle multiple client requests simultaneously.

---

## Network
A network is a group of interconnected devices that can communicate with each other.

### Examples
- Home WiFi network
- Office network
- The Internet

Networks allow computers to share data and services.

---

## Protocol
A protocol is a set of rules that define how devices communicate over a network.

Protocols define:
- How messages are structured
- Which commands are allowed
- How requests and responses should look
- How errors are handled

### Examples
- HTTP
- HTTPS
- FTP
- SMTP
- TCP/IP

Without protocols, computers would not understand each other's messages.

---

## Port
A port is a logical number used to identify a specific service running on a system.

A single server can run multiple services simultaneously, each on a different port.

### Examples of Common Ports

| Port | Service |
|-----|--------|
| 80 | HTTP |
| 443 | HTTPS |
| 21 | FTP |
| 22 | SSH |
| 25 | SMTP |

Example : If a web server runs on port 80, clients must connect to that port to access the website.

---

## DNS (Domain Name System)
DNS translates human-readable domain names into IP addresses.

### Example

`www.example.com` → 93.184.216.34

Computers communicate using IP addresses, but humans use domain names because they are easier to remember.

### DNS Process
1. User enters a website domain.
2. DNS server converts the domain into an IP address.
3. The client connects to the server using that IP address.

---

## Web Communication

The Hypertext Transfer Protocol (HTTP) is the main protocol used for communication on the World Wide Web.

### HTTP Characteristics
- Client-server protocol
- Used to request and transfer web resources
- Stateless protocol

---

## Stateless Protocol
HTTP is stateless, meaning :

- Each request is processed independently.
- The server does not remember previous requests.

Example : If you log into a website, the server normally would not remember your login on the next request.

To solve this, websites use mechanisms such as :
- Cookies
- Session IDs
- Authentication tokens

These help maintain session state.

---

## HTTP Methods

HTTP uses methods (commands) to define what action the client wants to perform.

### Core HTTP Methods

| Method | Purpose |
|------|--------|
| GET | Retrieve data from server |
| POST | Send data to server |
| PUT | Update existing data |
| DELETE | Remove data |
| PATCH | Partially update data |
| HEAD | Retrieve headers only |
| OPTIONS | Show supported methods |
| CONNECT | Establish tunnel connection |
| TRACE | Diagnostic request |

---

## GET Method

The GET method is used to retrieve data from a server.

### Example

`GET https://example.com/index.html`


This request asks the server to return the index page of the website.

When the server receives the request :
1. It processes the request.
2. It sends a response back to the client.

---

## HTTP Request and Response

When a client communicates with a server, the process includes :

1. Client Request
2. Server Response

---

## HTTP Request

A request contains information such as :

| Field | Description |
|------|-------------|
| Scheme | Protocol used (HTTP or HTTPS) |
| Host | Domain name of the server |
| Filename | Requested resource |
| Address | Server IP address |

### Example URL

`https://www.iamlearning.thm/contact`


| Component | Value |
|----------|------|
| Scheme | https |
| Host | `www.iamlearning.thm` |
| Path | /contact |

---

## HTTP Response

A server response contains two parts :

### Response Header
Contains metadata about the response.

Examples :
- Content type
- Server information
- Response status

### Response Body
Contains the actual content requested by the client.

Examples :
- HTML page
- Images
- CSS
- JavaScript

---

## HTTP Status Codes

Status codes indicate the result of a request.

| Code | Meaning |
|----|------|
| 200 | OK (request successful) |
| 301 | Moved permanently |
| 400 | Bad request |
| 403 | Forbidden |
| 404 | Not found |
| 500 | Internal server error |

Example : 200 OK

Means the server successfully processed the request.

---

## Example of Web Request Flow

1. User enters a website URL in the browser.
2. Browser queries DNS to get the server's IP address.
3. Browser sends an HTTP request to the server.
4. Server processes the request.
5. Server sends an HTTP response.
6. Browser displays the webpage.

---

## Summary

Key points :

- The Client-Server model allows systems to request and provide services.
- A client initiates requests.
- A server responds with resources or services.
- Protocols define how communication happens.
- Ports identify specific services on a server.
- DNS converts domain names into IP addresses.
- HTTP is the main protocol used for web communication.

This model is the foundation of how the Internet works.
