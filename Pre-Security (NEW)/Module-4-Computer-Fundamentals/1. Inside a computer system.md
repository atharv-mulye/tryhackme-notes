## Building Blocks of a Computer

Most computers share the same basic components. Each part has its role, and together they make the computer function.

### 1. Motherboard
- The motherboard is like the skeleton and nervous system of a computer.
- Holds all components in place and allows them to communicate.
- Key parts: CPU socket, RAM slots, expansion slots, and ports.
- All other components plug into or connect via the motherboard.

### 2. CPU (Central Processing Unit)
- Comparable to the brain of the computer.
- Executes instructions (like math, logic, or controlling other components).
- Modern CPUs have multiple cores to handle tasks in parallel.
- Connects to the motherboard via the CPU socket.

### 3. RAM (Random Access Memory)
- Works like short-term memory in our brain.
- Temporarily holds data that the CPU needs quick access to.
- Volatile memory : data is lost when power is turned off.
- Modern RAM uses DDR5 or DDR6 technology for higher speed.

### 4. Storage (HDD / SSD)
- Comparable to long-term memory.
- HDDs (Hard Disk Drives) use moving parts - slower but cheap and high capacity.
- SSDs (Solid State Drives) use memory chips - faster with no moving parts.
- Connect via SATA or PCI Express.

### 5. Network Adapter
- Lets the computer communicate with other systems, like vocal cords for humans.
- Can be wired (Ethernet) or wireless (Wi-Fi).
- Embedded on the motherboard or added via PCI Express card.

### 6. Power Supply Unit (PSU)
- Supplies power to all components, like the heart pumps blood.
- Connects to the outlet and distributes power through cables to the motherboard and devices.
- Insufficient PSU power can cause system failure.

### 7. Graphics Card
- Acts like the visual cortex of the brain.
- Processes visual data and outputs it to a monitor.
- Connects to the motherboard via PCI Express.

### 8. Input/Output Devices (I/O)
- Input devices : keyboard, mouse, microphone, scanner.  
- Output devices : monitor, printer, speakers.  
- Connect via USB, HDMI, DisplayPort, or other ports.
- Allow interaction with the computer, just as our senses interact with the brain.

**Summary:**  
A computer is like a mini “castle”:
- **Motherboard**: structure & communication  
- **CPU**: brain processing instructions  
- **RAM**: short-term memory  
- **Storage**: long-term memory  
- **Network Adapter**: communication  
- **PSU**: power supply  
- **Graphics Card**: visual processing  
- **I/O Devices**: senses to interact with the world

## What Happens When You Press the Start Button ?

### What is an Operating System (OS)?

- The OS is the main software that manages all hardware and software on a computer.  
- Examples: Windows, Linux, macOS.  
- The OS is permanently stored on a storage device but runs in RAM during operation.  

### Where is the OS Located ?

- **Storage Devices:**  
  - HDD (Hard Disk Drive) : Traditional spinning disk storage.  
  - SSD (Solid State Drive) : Fast storage with no moving parts.  
  - Bootable USB or external media : Used for live systems or recovery.  
- The OS resides permanently on these storage devices.  
- When the computer starts, the OS is loaded into RAM by the bootloader to run.

## Boot Process 

<img width="855" height="70" alt="image" src="https://github.com/user-attachments/assets/563be8b1-f2ea-45c7-a6a6-1d947062dd94" />

**1. Press Power Button**  
   - Powers up the computer and sends electricity to all components via the PSU.  

**2. Firmware Starts (UEFI/BIOS)**  
   - Initializes hardware components and prepares the system for the OS.  
   - Checks connected devices, CPU, RAM, and other essential components.  

**3. Power-On Self Test (POST)**  
   - Checks if all required hardware components are present and functioning correctly.  
   - If something fails, an error message or beep code is generated.  

**4. Select Boot Device**  
   - Firmware searches storage devices in a pre-defined order to find the bootloader.  

**5. Initiate Bootloader**  
   - The bootloader is a small program on the storage device that knows how to load the OS.  
   - Loads the OS from storage into RAM.  

**6. Operating System Takes Control**  
   - Once loaded into RAM, the OS starts managing hardware, memory, storage, and running programs.  
   - The computer is now ready for the user to interact with.  

### Why the OS Must Run in RAM

- Speed : RAM is much faster than storage, allowing the CPU to access OS instructions quickly.  
- CPU Execution : The CPU can only execute instructions from RAM, not directly from storage.  
- Fast Data Handling : The OS needs to read/write data constantly, which is only feasible in RAM.  
- Storage is Slow : HDDs/SSDs are for long-term storage, not for running programs in real-time.  

> The OS is stored on the disk but must be loaded into RAM to run efficiently.

### Key Points

- The OS cannot run directly from storage, it must be in RAM to operate.  
- Without an OS, the computer cannot manage hardware or run applications.  
- The bootloader acts as a bridge between firmware and OS, ensuring proper loading.
