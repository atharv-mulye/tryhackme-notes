# Virtualization Basics

## Introduction

In modern IT systems, companies run many applications such as websites, databases, email services, and internal tools.

In the past, each application required its own physical server, which caused several problems:
- High hardware cost
- Low resource utilization
- Slow deployment
- Difficult scaling

To solve these issues, virtualization was introduced.

Virtualization allows multiple virtual computers to run on a single physical server.

---

## What is Virtualization ?

Virtualization is a technology that allows multiple operating systems and applications to run on the same physical machine by creating virtual computers.

These virtual computers are called Virtual Machines (VMs).

Each VM behaves like a real computer, with its own:
- CPU
- RAM
- Storage
- Operating System
- Applications

But all VMs share the same physical hardware.

---

## Why Virtualization is Important

Before virtualization : One Server = One Application

This caused several problems.

---

## Problems with Physical Servers

### 1. High Cost
Organizations had to buy many physical servers.

Extra costs included :
- Electricity
- Cooling
- Maintenance
- Data center space

### 2. Low Hardware Utilization

Most applications used only 5–20% of server capacity.

This means :
- CPU power was wasted
- Memory was unused
- Storage was underutilized

### 3. Slow Deployment

Setting up a new physical server could take:
- Days
- Weeks

### 4. Hard to Scale

If an application needed more resources:
- Companies had to purchase another server.

---

## Virtualization Solution

Virtualization allows multiple applications to share a single physical server safely.

This is done using a software layer called a Hypervisor.

---

## Main Components of Virtualization

## 1. Hypervisor

A hypervisor is software that creates and manages Virtual Machines.

### Functions of a Hypervisor

- Divides physical hardware into virtual machines
- Allocates CPU, RAM, and storage to VMs
- Keeps VMs isolated from each other
- Starts, stops, and manages VMs

---

## Types of Hypervisors

### Type 1 Hypervisor (Bare Metal)

Runs directly on the physical hardware.

Characteristics :
- High performance
- More secure
- Used in data centers

Examples :
- VMware ESXi
- Microsoft Hyper-V
- Xen

Best used for :
- Production servers
- Databases
- Data centers

### Type 2 Hypervisor (Hosted)

Runs inside an existing operating system.

Characteristics :
- Easy to install
- Used for testing and learning

Examples :
- Oracle VirtualBox
- VMware Workstation
- Parallels

Best used for :
- Learning virtualization
- Testing software
- Running Kali Linux labs

---

## 2. Virtual Machines (VMs)

A Virtual Machine (VM) is a virtual computer created by a hypervisor.

Each VM contains :
- Virtual CPU
- Virtual RAM
- Virtual disk
- Virtual network interface
- Operating system

### Features of VMs

- Fully isolated from other VMs
- Can run different operating systems
- Behave like real computers

### Example Uses

- Running Kali Linux for cybersecurity practice
- Testing suspicious files safely
- Running multiple servers on one machine

---

## 3. Containers

A container is a lightweight environment used to run applications.

Unlike virtual machines, containers do not include a full operating system.

Instead, containers share the host system’s kernel.

## Container Characteristics

Containers :

- Package an application and its dependencies
- Start very quickly
- Use fewer resources
- Are isolated from other containers

## Containers vs Virtual Machines

| Feature | Virtual Machines | Containers |
|-------|------------------|-----------|
| OS Included | Yes | No |
| Resource Usage | Higher | Lower |
| Startup Time | Slower | Very fast |
| Isolation | Strong | Moderate |
| Use Case | Full systems | Applications |

---

## Docker

Docker is the most popular platform used to run containers.

Docker allows developers to :
- Build applications
- Package them into containers
- Deploy them anywhere

---

# Virtualization Management

Organizations use Virtualization Management Tools to manage VMs.

These tools allow administrators to :

- Monitor system status
- Create new virtual machines
- Restart or stop VMs
- Monitor hardware usage
- Manage multiple hosts

---

## Virtual Machine States

A virtual machine can have different states :

| State | Meaning |
|------|--------|
| Running | VM is active |
| Stopped | VM is powered off |
| Paused | VM temporarily suspended |
| Error | VM encountered a problem |

Administrators can restart or repair VMs if issues occur.

---

## Creating a Virtual Machine

When creating a VM, you must define the hardware resources:

Example configuration :

| Setting | Example |
|-------|---------|
| Name | Marketing-VM |
| CPU Cores | 4 |
| Memory | 8 GB |
| Disk Size | 100 GB |

After creation, the VM appears in the virtualization manager and can be started.

---

## Monitoring Physical Hosts

Virtualization managers also monitor physical servers (hosts).

Administrators analyze :

- CPU usage
- Memory usage
- VM distribution
- Hardware health

Example observations :

- A host with low usage can run more VMs.
- A host at 100% capacity may require scaling.
- A disconnected host cannot run VMs.

---

## Key Terms 

| Term | Meaning |
|-----|--------|
| Virtualization | Running multiple virtual computers on one physical machine |
| Hypervisor | Software that creates and manages virtual machines |
| Virtual Machine (VM) | A virtual computer running inside a hypervisor |
| Container | Lightweight environment for running applications |
| Host | Physical machine running virtualization |
| Guest | Virtual machine running inside the host |

---

## Key Takeaways

- Virtualization allows multiple systems to share one physical server.
- It improves hardware utilization and reduces costs.
- A hypervisor manages virtual machines.
- VMs provide full system isolation.
- Containers provide lightweight application environments.
- Virtualization is a core technology behind cloud computing and modern infrastructure.
