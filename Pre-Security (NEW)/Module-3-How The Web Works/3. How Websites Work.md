# How Websites Work

## How Websites Work

When you visit a website, your browser (like Chrome, Firefox, or Safari) sends a request to a web server asking for information about the page you want to visit. The web server is just a computer somewhere else in the world that handles your request and sends back data that your browser uses to display the page.

### Major Components of a Website

Websites have two main parts :

1. **Front End (Client-Side)**  
   - This is what you see and interact with in your browser.  
   - Includes HTML, CSS, JavaScript, images, videos, and other content.  
   - Responsible for rendering the page and providing a user interface.

2. **Back End (Server-Side)**  
   - The server processes your requests and sends back the appropriate response.  
   - Includes server software, databases, application logic, and APIs.  
   - Handles data storage, authentication, and business logic.

### How It Works 

1. You type a URL in your browser or click a link.  
2. The browser sends a request to the server that hosts the website.  
3. The server processes the request and returns the necessary data.  
4. The browser renders the page using front-end technologies so you can see and interact with it.

> **Key Idea:** You make a request to a server, and the server responds with data that your browser uses to show the website.  

**Tip :** Understanding how front-end and back-end interact is crucial for identifying potential vulnerabilities and security issues in websites.

---

Websites are primarily built using three core technologies:

- **HTML** – defines the structure of a webpage  
- **CSS** – adds styling to make websites look appealing  
- **JavaScript** – adds interactivity and complex features  

---

## What is HTML ?

HTML (HyperText Markup Language) is the language used to create web pages.  
It uses elements (tags) as building blocks to tell the browser how to display content.  

A simple HTML document looks like this:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>
    <h1>Welcome to My Website</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```

## Components of an HTML Document

- **`<!DOCTYPE html>`**
- Declares that the page is an HTML5 document.
- Helps browsers standardize how they display the page.

- **`<html>`**
- The root element of the HTML page.
- All other elements are nested inside this element.

- **`<head>`**
- Contains meta-information about the page (e.g., title, scripts, styles).

- **`<body>`**
- Contains the visible content of the page.

---

## Common HTML Elements
- **`<h1> … <h6>`** – headings
- **`<p>`** – paragraph
- **`<button>`** – button
- **`<img>`** – image
- **`<ul>` / `<ol>` / `<li>`** – lists

---

## Attributes in HTML

- **`class`** – used to style multiple elements with the same class  
  ```
  <p class="bold-text">This is a bold paragraph</p>
  ```

- **`id`** – unique identifier for an element, used for styling or JavaScript
```
<p id="unique-example">This is a unique paragraph</p>
```

- **`src`** – specifies the source of images or media
```
<img src="img/cat.jpg" alt="Cat Image">
```

- An element can have multiple attributes:
```
<p attribute1="value1" attribute2="value2">Text</p>
```

**Viewing HTML :**

- You can view the HTML of any website by:
- Chrome: Right-click → “View Page Source”
- Safari: Right-click → “Show Page Source”
  
> Note : HTML forms the backbone of a webpage – everything you see on the site is structured using HTML elements.

## JavaScript (JS)

JavaScript is one of the most popular coding languages and allows web pages to become interactive. 

- **HTML**: Used to create the website structure and content.  
- **JavaScript**: Controls the functionality of web pages. Without JS, a page would be static and non-interactive.  

JS can dynamically update content in real-time, such as:  
- Changing the style of a button when clicked  
- Displaying moving animations  
- Updating page content without reloading  

---

### Adding JavaScript to a Page

JavaScript can be added in two ways:

**1. Inline with `<script>` tags :**
```html
<script>
    // JavaScript code here
</script>
```

**2. External JS file using src attribute :**
```
<script src="/location/of/javascript_file.js"></script>
```
---

**1. Example : Modifying Page Content**<br>
This JavaScript code finds an HTML element with the ID demo and updates its content:
```
<p id="demo">Original Text</p>

<script>
    document.getElementById("demo").innerHTML = "Hack the Planet";
</script>
```
**Explanation:** The text inside the element with ID demo changes to "Hack the Planet".

**2. Example: JavaScript Events** <br>
HTML elements can have events like onclick or onhover that execute JS when triggered.
```
<p id="demo">Original Text</p>
<button onclick='document.getElementById("demo").innerHTML = "Button Clicked";'>
    Click Me!
</button>
```
**Explanation:** When the button is clicked, the text in the element with ID demo changes to "Button Clicked".

> Note : Event handlers like onclick can also be defined inside <script> tags instead of directly in the HTML element.

## Sensitive Data Exposure

Sensitive Data Exposure occurs when a website fails to properly protect or remove sensitive information, often leaving it visible in clear-text to the end-user. This is commonly found in a site's frontend source code.


### How It Happens

Websites are built using HTML elements (tags) and JavaScript, all of which can be viewed using "View Page Source" in a browser.  

A developer may forget to remove:

- Login credentials
- Hidden links to private parts of the website
- API keys or tokens
- Other sensitive data

This exposed information can be leveraged by attackers to gain unauthorized access to different parts of a web application.

## HTML Injection

HTML Injection is a vulnerability that occurs when a website displays unfiltered user input directly on the page.  

If a website fails to sanitize user input (i.e., remove or neutralize potentially harmful HTML or JavaScript), an attacker can inject their own HTML code into a vulnerable page.


### How It Works

1. User input is sent to the website (e.g., via a form).  
2. The website outputs the input without sanitization.  
3. The browser renders the input as HTML (or JavaScript).  
4. The attacker can now control the page's appearance or behavior.
