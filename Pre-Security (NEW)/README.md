## 📌 About

This folder contains my journey through the Pre Security path.  
It focuses on building a strong base in cybersecurity by understanding how systems, networks, and the web actually work before moving into deeper security topics.

---

## 🎯 Objective

- Build a solid foundation in cybersecurity  
- Understand how systems and networks operate  
- Learn how the web functions behind the scenes  
- Develop an attacker + defender mindset
