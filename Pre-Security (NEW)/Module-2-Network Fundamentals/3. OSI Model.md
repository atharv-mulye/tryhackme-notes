# OSI (Open Systems Interconnection) Model

## What is the OSI Model?

The OSI model (Open Systems Interconnection Model) is a conceptual framework used in networking to describe how data is transmitted and received across a network.

It standardizes communication by dividing networking processes into seven distinct layers. Each layer has specific responsibilities and works together to ensure data is correctly sent, received, and interpreted.

One major benefit of the OSI model is interoperability. Devices with different hardware designs and software implementations can communicate effectively as long as they follow the OSI structure.

As data moves through the layers, each layer adds specific information. This process is called encapsulation.

# Layer 1 – Physical Layer

The Physical layer is the lowest and most fundamental layer.

## Responsibilities

- Transmits raw binary data (1s and 0s)
- Defines hardware specifications
- Controls voltage levels, cables, connectors, and data rates
- Handles electrical, light, or radio signals

## Examples

- Ethernet cables
- Fiber optics
- Network hubs
- Physical connectors

In short, Layer 1 handles the physical transmission of bits across the network.

---

# Layer 2 – Data Link Layer

The Data Link layer is responsible for physical addressing and framing.

## Responsibilities

- Adds MAC address to data
- Converts packets into frames
- Ensures data is formatted properly for transmission
- Handles communication within the same local network

Every network device has a Network Interface Card (NIC) with a unique MAC address.

MAC addresses are assigned by manufacturers and are typically permanent (though they can be spoofed).

Switches operate at Layer 2.

In short, Layer 2 ensures data reaches the correct device on the same local network.

---

# Layer 3 – Network Layer

The Network layer handles logical addressing and routing.

## Responsibilities

- Assigns and manages IP addresses
- Determines the best path for data transmission
- Routes packets between different networks
- Reassembles fragmented packets

Everything at this layer works using IP addresses such as:

`192.168.1.100`

Routing decisions may consider:

- Shortest path (fewest hops)
- Reliability
- Speed of connection (copper vs fiber)

Common routing protocols:

- OSPF (Open Shortest Path First)
- RIP (Routing Information Protocol)

Routers operate at Layer 3.

In short, Layer 3 delivers packets across different networks using IP addresses.

---

# Layer 4 – Transport Layer

The Transport layer ensures reliable or fast data delivery between devices.

It uses two main protocols:

- TCP (Transmission Control Protocol)
- UDP (User Datagram Protocol)

---

## TCP (Transmission Control Protocol)

TCP is reliable and connection-oriented.

### Features

- Establishes a stable connection
- Guarantees delivery
- Performs error checking
- Reassembles data in correct order
- Controls data flow

### Advantages

- Accurate and complete data transfer
- Prevents device flooding
- Reliable communication

### Disadvantages

- Slower than UDP
- Requires continuous connection
- More processing overhead

### Used For

- Web browsing
- Email
- File transfers

TCP is ideal when accuracy is critical.

---

## UDP (User Datagram Protocol)

UDP is fast and connectionless.

### Features

- No connection setup
- No delivery guarantee
- No error checking
- Sends data immediately

### Advantages

- Faster than TCP
- Lower overhead
- Efficient for real-time applications

### Disadvantages

- Data may be lost
- No retransmission
- Unstable connections affect quality

### Used For

- Video streaming
- Online gaming
- VoIP
- ARP and DHCP communication

UDP is ideal when speed is more important than perfection.

In short, Layer 4 controls how data is transported — reliably (TCP) or quickly (UDP).

---

# Layer 5 – Session Layer

The Session layer manages communication sessions between devices.

## Responsibilities

- Establishes sessions
- Maintains active connections
- Terminates sessions
- Implements checkpoints (synchronization)

If data transmission is interrupted, only the missing portion after the checkpoint needs to be retransmitted.

Each session is unique, and data cannot move between separate sessions.

In short, Layer 5 manages and controls communication sessions.

---

# Layer 6 – Presentation Layer

The Presentation layer handles data formatting and translation.

## Responsibilities

- Translates data formats
- Encrypts and decrypts data
- Compresses data
- Standardizes data representation

For example:

- Different email clients can display the same message format.
- HTTPS encryption occurs at this layer.

In short, Layer 6 ensures data is readable, properly formatted, and secure.

---

# Layer 7 – Application Layer

The Application layer is the closest layer to the user.

It defines how software applications interact with the network.

## Responsibilities

- Provides user interface access to network services
- Implements application-level protocols
- Facilitates communication between software and network

Common protocols:

- HTTP / HTTPS (Web browsing)
- SMTP / IMAP / POP3 (Email)
- FTP (File transfer)
- DNS (Domain name resolution)

DNS translates domain names into IP addresses such as:

`192.168.1.100`

Applications like web browsers, email clients, and file transfer software operate at this layer.

In short, Layer 7 is where users interact with network services.

---

# Summary of OSI Layers

| Layer | Name | Main Responsibility |
|-------|------|---------------------|
| 7 | Application | User interaction and network services |
| 6 | Presentation | Formatting, encryption, translation |
| 5 | Session | Session management |
| 4 | Transport | Reliable or fast data transport (TCP/UDP) |
| 3 | Network | Routing and IP addressing |
| 2 | Data Link | MAC addressing and framing |
| 1 | Physical | Transmission of raw bits |

---

## Key Takeaways

- The OSI model standardizes network communication.
- It consists of seven layers, each with specific responsibilities.
- Encapsulation occurs as data moves through layers.
- TCP and UDP operate at Layer 4.
- Routers operate at Layer 3.
- Switches operate at Layer 2.
- Physical transmission occurs at Layer 1.
