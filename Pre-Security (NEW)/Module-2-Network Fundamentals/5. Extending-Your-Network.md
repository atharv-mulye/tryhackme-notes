# Extending Your Network

## Introduction to Port Forwarding

Port forwarding allows devices on the Internet to access a specific service running inside a private (internal) network.

Without port forwarding, services such as web servers are only accessible within the same local network (intranet).

### Example Scenario

Port forwarding is an essential component in connecting applications and services to the Internet. Without port forwarding, applications and services such as web servers are only available to devices within the same direct network. Take the network below as an example. Within this network, the server with an IP address of "192.168.1.10" runs a webserver on port 80. Only the two other computers on this network will be able to access it (this is known as an intranet).

Traffic sent to : `82.62.51.70:80`

This allows external users to access the internal web server.

### Important Distinction

Port Forwarding:
- Opens a port on the router
- Redirects incoming traffic to a specific internal IP and port

Firewall:
- Decides whether that traffic is allowed or blocked
- Filters traffic based on defined rules

Port forwarding is configured on the router.

## Firewall

### What is a Firewall?

A firewall is a security device (hardware or software) that controls what network traffic is allowed to enter or leave a network.

It acts like border security for your network.

Every packet of data that tries to enter or exit the network is checked against predefined rules. Based on those rules, the firewall either:

- Allows the traffic  
- Blocks the traffic  

---

## What Does a Firewall Check?

A firewall filters traffic based on several factors:

- **Source IP Address**  
  → Where is the traffic coming from?

- **Destination IP Address**  
  → Where is the traffic going?

- **Port Number**  
  → Which service is being accessed? (e.g., port `80` for HTTP)

- **Protocol**  
  → Is the traffic using TCP or UDP?

Before allowing traffic, the firewall performs packet inspection to make its decision.

---

## Where Do Firewalls Exist?

Firewalls can be implemented in different forms:

- **Dedicated hardware appliances**  
  → Used in enterprise or large business networks  

- **Residential routers**  
  → Home routers usually include a built-in firewall  

- **Software firewalls**  
  → Installed on individual systems (e.g., Snort, Windows Firewall)

---

## Types of Firewalls

There are two main types of firewalls :


### 1. Stateful Firewall

A **stateful firewall** monitors the entire connection, not just individual packets.

**Key Features:**

- Tracks the state of a session
- Monitors full TCP handshakes
- Makes dynamic decisions
- Uses more system resources

**How It Works:**

Instead of checking packets separately, it keeps track of the entire communication session.

Example:
If a TCP handshake starts normally but later behaves suspiciously, the firewall can:

- Block the entire connection  
- Block the device completely  

Stateful firewalls are smarter and more secure, but they require more processing power.

---

### 2. Stateless Firewall

A stateless firewall checks each packet individually.

**Key Features:**

- Uses a fixed (static) rule set
- Does not track session state
- Uses fewer system resources
- Faster but less intelligent

**Limitation:**

If traffic does not exactly match a blocking rule, malicious packets might pass through.

Stateless firewalls do not understand context — they only compare packets against predefined rules.

---

## When to Use Stateless Firewalls?

Stateless firewalls are useful for:

- High-speed networks
- Handling very large traffic volumes
- DDoS mitigation environments

They are lightweight and efficient but offer less detailed inspection.

---

## Stateful vs Stateless Comparison

| Feature | Stateful Firewall | Stateless Firewall |
|----------|------------------|-------------------|
| Tracks connection state | Yes | No |
| Inspects full session | Yes | No |
| Resource usage | Higher | Lower |
| Security level | Higher | Moderate |
| Best for | Enterprise security | High-speed filtering |

---

## Key Points 

- A firewall controls incoming and outgoing network traffic.
- It filters traffic based on IP address, port, and protocol.
- Firewalls can be hardware or software.
- Stateful firewalls track entire connections and offer better security.
- Stateless firewalls inspect packets individually and are faster but less intelligent.

Firewalls are a critical part of network security and help protect systems from unauthorized access.

## VPN Basics

### What is a VPN?

A Virtual Private Network (VPN) creates an encrypted tunnel between two networks over the Internet.

Devices connected through this tunnel form a private network, even if they are geographically distant.

VPNs are used to:

- Connect remote offices
- Allow employees to work from home securely
- Protect traffic on public WiFi
- Access private lab environments (like TryHackMe)

---

Example : Two offices (Network #1 and Network #2) can be securely connected through a VPN, creating Network #3 (the VPN network). Devices remain part of their original networks but can also privately communicate over the VPN.

## Benefits of VPN

### 1. Connects Remote Networks

Businesses with multiple offices can share infrastructure securely.

### 2. Privacy

- Encrypts data
- Prevents traffic sniffing
- Protects communication on public networks

### 3. Anonymity

- Hides traffic from ISP
- Reduces tracking
- Useful in restricted regions

Note : Privacy depends on the VPN provider. If a VPN logs activity, anonymity is reduced.

---

## VPN Technologies

### PPP (Point-to-Point Protocol)

- Provides authentication and encryption
- Uses private key and public certificate
- Non-routable (cannot leave network alone)
- Used inside PPTP

### PPTP (Point-to-Point Tunneling Protocol)

- Allows PPP data to travel outside network
- Easy to configure
- Weak encryption compared to modern standards

### IPSec (Internet Protocol Security)

- Encrypts data using IP framework
- Strong encryption
- More complex to configure
- Widely supported

## Networking Devices

### Router

A router connects different networks and routes data between them.

Routers operate at : Layer 3 (Network Layer)

Responsibilities:

- Routing packets between networks
- Selecting best path
- Configuring port forwarding
- Managing firewall rules

Routing decisions depend on:

- Shortest path
- Most reliable path
- Fastest transmission medium

Routers connect separate networks.

---

### Switch

A switch connects multiple devices within the same network.

Supports approximately 3–63 devices using Ethernet cables.

Switches operate at : Layer 2 or Layer 3

**Layer 2 Switch**

- Forwards frames using MAC addresses
- Does not perform routing
- Works within same network

Responsible only for correct frame delivery.

**Layer 3 Switch**

- Forwards frames (Layer 2 function)
- Routes packets using IP (Layer 3 function)
- Can connect multiple subnets

Example IPs in different subnets:

`192.168.1.1`  
`192.168.2.1`

Layer 3 switches can route between these networks.

## VLAN (Virtual Local Area Network)

VLAN allows a single physical network to be logically divided into multiple isolated networks.

Benefits:

- Network segmentation
- Improved security
- Traffic management

Example:

Sales Department VLAN  
Accounting Department VLAN  

Both can:

- Access Internet

But cannot:

- Communicate directly with each other

Even though they are connected to the same physical switch.

> A technology often used with Layer 3 switches is VLAN (Virtual Local Area Network), which allows a single physical network to be virtually segmented into multiple logical networks. VLANs enable devices to share the same physical switch while remaining isolated from each other, improving both security and traffic management. For example, devices in a "Sales Department" VLAN and an "Accounting Department" VLAN can both access the Internet through the same switch but cannot directly communicate with each other, enforcing network policies and separation.
