# What is Networking?

## Overview

Networking is the concept of connecting devices so they can communicate and share resources. While networks exist in everyday life (such as transportation systems or power grids), in computing, networking refers to interconnected technological devices exchanging data using defined rules called protocols.

A network can range from two devices to billions of connected systems worldwide.

---

## Everyday Examples of Networks

Networks are not limited to computing. Examples include:

- Public transportation systems
- National power grids
- Postal systems
- Community and social groups

The same principle applies in computing - devices are connected to exchange information.

---

# The Internet

## What is the Internet?

The Internet is a global network of interconnected smaller networks.

It allows devices worldwide to:

- Communicate  
- Share information  
- Access services  
- Host applications  

It is often referred to as a "network of networks."

---

## Brief History

- Late 1960s: ARPANET becomes the first operational computer network.
- 1989: Tim Berners-Lee invents the World Wide Web (WWW).
- Modern Era: The Internet evolves into a global communication and data exchange platform.

---

# Identifying Devices on a Network

For devices to communicate properly, they must be identifiable.

Similar to humans having:
- A name (changeable)
- Fingerprints (unique and permanent)

Devices have:
- IP address (logical, changeable)
- MAC address (physical, usually permanent)

---

# IP Address

An IP address identifies a device on a network.

Example:

An IPv4 address:

- Contains four octets  
- Uses 32 bits  
- Allows approximately 4.29 billion addresses  

Within the same network, two devices cannot share the same IP address simultaneously.

---

## Public vs Private IP Address

### Private IP Address

- Used inside local networks  
- Example: `192.168.1.77`  
- Devices use these to communicate locally  

### Public IP Address

- Assigned by an Internet Service Provider (ISP)  
- Used to identify a network on the Internet  
- Multiple devices can share one public IP address using a router  

Example:

Private IPs:
- `192.168.1.77`
- `192.168.1.74`

Shared Public IP:
- `86.157.52.21`

Inside the network:
- Devices have unique private IP addresses

Outside (on the Internet):
- They appear to share the same public IP address

---

# IPv4 Exhaustion

IPv4 supports approximately 4.29 billion addresses.

With billions of connected devices worldwide, this address space became insufficient — leading to IPv4 exhaustion.

# MAC Address

A MAC address (Media Access Control address) is:

- A 12-character hexadecimal value  
- Assigned to the network interface at the factory  
- Structured as :

<img width="300" height="300" alt="image" src="https://github.com/user-attachments/assets/9fbd5978-9f77-43b4-8b3c-c0735a262056" />


- First 6 characters → Manufacturer identifier  
- Last 6 characters → Unique device ID  

A MAC address functions as a hardware-level identifier.

---

## MAC Address Spoofing

A MAC address can be impersonated in a process known as spoofing.

If a system relies only on MAC address filtering for access control, it may be vulnerable to bypass techniques.

---

# Ping and ICMP

Ping is a fundamental network diagnostic tool.

It uses ICMP (Internet Control Message Protocol) to:

- Send an Echo Request  
- Receive an Echo Reply  
- Measure latency  
- Detect packet loss  

Example:

Pinging Google DNS server:
`8.8.8.8`

Ping helps determine:

- If a host is reachable  
- Response time  
- Connection reliability

# Key Takeaways

- Networking connects devices to share data and services.
- The Internet is a global network of interconnected smaller networks.
- Devices are identified using IP addresses and MAC addresses.
- IPv6 solves IPv4 address limitations.
- MAC address filtering alone is not secure.
- Ping is essential for network diagnostics.
