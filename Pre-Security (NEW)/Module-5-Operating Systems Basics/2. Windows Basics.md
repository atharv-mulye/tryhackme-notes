# Windows Basics

## History of Windows

---

### MS-DOS Era
- MS-DOS (Microsoft Disk Operating System) was released in 1981.
- It provided a command-line interface (CLI) where users typed text commands to manage files and run programs.
- Features :
  - Black screen interface with text-based navigation.
  - Users needed to know specific commands like `DIR` (list files) and `COPY` (copy files).
  - Minimal multitasking – could usually run only one program at a time.
- Limitations :
  - No graphical interface, which made it less intuitive for casual users.
  - Required manual memory and hardware management, which could be tricky for non-technical users.

### Windows 1.0
- Released in 1985 as a GUI on top of MS-DOS.
- Introduced graphical elements :
  - Windows : overlapping screens for multitasking.
  - Menus : drop-down options to simplify tasks.
  - Mouse support : enabled point-and-click navigation.
- Initially very basic; many applications still required DOS commands.

### Windows Evolution
- Over time, Windows versions added more features:
  - Windows 3.x (1990-1992) : improved graphics, better file management, Program Manager interface.
  - Windows 95 : introduced Start menu , taskbar, plug-and-play hardware support.
  - Windows XP / Vista / 7 / 8 / 10 / 11 : progressively refined interface, security, networking, and multitasking capabilities.
- Modern Windows is the result of gradual improvements in usability, functionality, and system stability.
- Today, Windows provides a full-featured operating system with graphical interface, networking, security, and a wide range of built-in apps.

## Logging in and Authentication

Before accessing the Windows Desktop, users must authenticate (prove their identity).

**What is Authentication ?**
- Process of verifying a user’s identity
- Determines what actions a user is allowed to perform
- Required at system startup via the login screen

**Authentication Methods**
- Password
- PIN
- Other verification methods (e.g., biometrics)

## User Account Types

### Guest
- Temporary access
- Very limited permissions
- Cannot change system settings

### Standard User
- Used for everyday tasks
- Can run applications and modify personal settings
- Cannot make system-wide changes

### Administrator
- Full control over the system
- Can:
  - Install software
  - Change system settings
  - Manage users

### Key Point
- Each account has permission levels that control access to:
  - Files
  - Settings
  - System features

## Windows Desktop

The Windows Desktop is the main workspace you see after logging in.

### Core Areas
- **Desktop** → Main workspace for files, folders, and shortcuts

---

## Desktop Components

### Desktop Icons
- Shortcuts to :
  - Recycle Bin
  - Files/Folders
  - Applications
- Fully customizable

### Start Menu
- Central access point for:
  - Applications
  - Settings
  - Power options (shutdown/restart)
- Open via Windows icon (bottom-left)

### Search
- Quickly find :
  - Apps
  - Files
  - Settings

### Task View
- Shows all open windows
- Allows quick switching between tasks

### Pinned Apps
- Frequently used apps/folders for quick access

### System Tray (Right Side of Taskbar)
- **Network & Audio** settings  
- **Date & Time** (calendar access)  
- **Notifications**

## Configuring and Securing Windows

## Application Management

Applications are programs used to perform tasks on a computer. Managing them properly ensures system performance and security.

### Updating Applications

#### Windows Update
- Built-in tool to update:
  - Operating System
  - Security features
  - Native apps
- Accessible via Settings
- Can run automatically

#### App Update Methods
- Built-in apps → Auto-update
- Third-party apps → Own update systems
- Some apps:
  - Prompt on launch
  - Require manual update

## Task Manager

Monitors system processes and performance in real time.

### Tabs
- **Processes** → Running apps & resource usage  
- **Performance** → CPU, RAM, network stats  
- **Users** → Logged-in users  
- **Details** → Advanced process info (PID)  
- **Services** → Background services status  

---

## Windows Security

Central dashboard for system protection.

### Core Sections
- **Virus & Threat Protection**
  - Malware detection
  - Real-time protection
  - Custom scans

- **Firewall & Network Protection**
  - Controls traffic
  - Prevents unauthorized access

- **App & Browser Control**
  - Blocks unsafe apps/files/websites

- **Device Security**
  - Hardware-based protections

---

## Windows Defender Firewall

Protects system from unauthorized network access.

### Network Profiles
- **Domain** → Organization network  
- **Private** → Trusted network  
- **Public** → Untrusted network  

### Features
- Inbound & outbound rules
- Allow/block applications
- Advanced filtering options

## Key Takeaways
- Keep system updated for security and stability
- Install apps from trusted sources
- Use Task Manager for monitoring performance
- Windows Security provides built-in protection
- Firewall controls network access and traffic

## Summary 

**Key Terminology**

- Desktop: The main workspace where files, folders, and shortcuts live
- Taskbar: A control strip that provides access to applications, tools, settings, and notifications
- Start Menu: The primary way to access applications, settings, and power options, signified by the Windows logo
- Search: A quick access method of locating applications, settings, and files by entering search terms
- File Explorer: The built-in Windows tool to browse, manage, and organize files and folders
- Windows Update: A built-in update tool that helps keep your OS, native apps, and security features up to date
- Microsoft Store: The native Windows application for installing trusted applications
- Windows Settings: A centralized location for configuring system, device, personalization, and security settings
- Control Panel: The legacy management interface that provides access to system configuration options
- Task Manager: A Windows tool for monitoring what is happening on your system in real time
- Windows Security: The central dashboard for managing Windows built-in security tools
- Windows Defender Firewall: The firewall designed to help protect your system from unauthorized network traffic
