# Operating System (OS) Introduction

## Introduction

Every day you turn on your phone or laptop, open apps, play music, browse the internet, and work with files. Everything seems to work smoothly and automatically.

But behind the scenes, something is managing all these tasks.  
That system is called the Operating System (OS).

An Operating System is the software that connects the user with the computer hardware and manages all the system resources.

Without an operating system, a computer would not be able to run applications or interact with the user.

---

## What is an Operating System ?

An Operating System (OS) is the core software that manages computer hardware and software resources and provides services for programs.

It acts as a bridge between the user, applications, and hardware.

### Example

When you open a browser :
1. You click the browser icon.
2. The Operating System loads the program into RAM.
3. The CPU executes the instructions.
4. The OS manages memory, storage, and input/output devices.

Without the OS, applications would have to directly control hardware, which would be extremely complex.

---

## Role of the Operating System

The OS performs several important tasks to keep the system running smoothly.

### 1. Process Management
The OS manages running programs (called processes).

Example :
- Running a browser
- Playing music
- Editing a document

The OS ensures all programs get CPU time without crashing the system.

### 2. Memory Management
The OS controls RAM usage.

It :
- Allocates memory to programs
- Frees memory when programs close
- Prevents programs from interfering with each other

### 3. File System Management
The OS manages files and folders stored on disks.

Example operations :
- Creating files
- Deleting files
- Organizing folders
- Reading and writing data

### 4. Device Management
The OS controls hardware devices such as :

- Keyboard
- Mouse
- Monitor
- Printer
- Storage devices

It uses device drivers to communicate with hardware.

### 5. User Interface
The OS provides a way for users to interact with the system.

Two common types :

**GUI (Graphical User Interface)**  
Example :
- Windows
- macOS

**CLI (Command Line Interface)**  
Example :
- Linux Terminal
- Command Prompt

## Common Operating Systems

Some popular operating systems include :

### Windows
- Most common desktop OS
- Used for gaming, office work, and general use

### Linux
- Open-source OS
- Popular for servers, cybersecurity, and development

### macOS
- Used on Apple computers
- Known for stability and design

### Android
- Mobile operating system used on smartphones

### iOS
- Apple’s mobile operating system

---

## Key Idea

The Operating System is the most important software on a computer.

It :
- Controls hardware
- Runs applications
- Manages system resources
- Provides the interface for users

Without an OS, a computer would not function in a usable way.

---

## Quick Summary

- An Operating System (OS) manages computer hardware and software.
- It acts as a bridge between users and hardware.
- It manages processes, memory, files, and devices.
- It provides interfaces like GUI and CLI.
- Examples include Windows, Linux, macOS, Android, and iOS.
