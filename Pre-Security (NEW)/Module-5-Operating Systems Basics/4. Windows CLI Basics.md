# Windows CLI Basics

## Introduction
- Windows is one of the most widely used operating systems in workplaces.
- In cybersecurity, many investigations involve Windows systems (especially user machines).
- Learning the Windows Command Line helps in troubleshooting, analysis, and system investigation.

## What is the Windows Command Line ?
- The Command Prompt (CMD) is a text-based interface to interact with Windows.
- Instead of using a mouse, commands are typed to perform actions.
- It allows users to :
  - Navigate files and folders
  - Search for files
  - View system information

### Why use CLI ?
- Faster than graphical interface
- Provides more control
- Required for many security tools and tasks

---

## File Navigation and Management

**1. Understanding Your Location**
- The terminal always operates from a current directory (working directory).
- Knowing your location is essential before performing any actions.

Command : `cd` - Displays your current directory path

**2. Viewing Directory Contents**
- You can list files and folders inside the current directory.
- Some files are hidden by default and not visible in normal listings.

Command : `dir` - Shows visible files and folders

**3. Hidden Files**
- Windows hides certain system or configuration files.
- Hidden does not mean secret, just not shown by default.

Command : `dir /a` - Shows all files, including hidden ones

**4. Moving Between Directories**
- You can navigate into folders or move back to previous directories.
- This allows exploration of the file system structure.

Commands :

- `cd folder_name` - Move into a folder
- `cd ..` - Move back one directory

**5. Searching for Files**
- Instead of manually browsing, you can search for files by name.
- The system can recursively search through folders.
- Useful when you don’t know the file location.

Command : `dir /s filename.txt` - Searches for a file in all subdirectories

**6. Reading File Contents**
- Text files can be opened and read directly in the terminal.
- No need to open external programs.

Command : `type filename.txt` - Displays file content in the terminal

## Gathering System Information & Commands

**1. User Identification**
- Shows which user is currently logged in.
- Important for understanding permissions.

Command : `whoami`

**2. System Identification**
- Displays the computer’s name.
- Useful in network environments.

Command : `hostname`

**3. Operating System Details**
- Provides detailed information about the OS.
- Includes version and system type.

Command : `systeminfo`


---

### Gathering Network Information

**1. Network Information**
- Shows how the system is connected to the network.
- Helps identify IP and gateway.

Command : `ipconfig`
