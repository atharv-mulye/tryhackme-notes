# Operating System Security

## What is an Operating System ?
- An Operating System (OS) acts as a middle layer between hardware and applications.
- Hardware (CPU, RAM, storage, keyboard, etc.) cannot function meaningfully without an OS.
- The OS manages hardware and allows applications to run properly.

### Key Idea
> Apps don’t talk directly to hardware-they go through the OS.

---

## Types of Operating Systems
- **Desktop/Laptop :** Windows, macOS  
- **Mobile :** Android, iOS  
- **Server :** Windows Server, Solaris, AIX  
- **Flexible (both) :** Linux  

---

## Why OS Security Matters
Devices store a lot of sensitive data:
- Personal files and photos
- Emails and messages
- Saved passwords
- Banking apps

If the OS is not secure, all this data is at risk.

---

## Core Security Principles (CIA Triad)

### Confidentiality
- Only authorized people should access data
- Prevents data leaks

### Integrity
- Data should not be modified without permission
- Ensures trust in files and systems

### Availability
- Systems and data should be accessible when needed
- Prevents downtime or denial of access

---

## Common Security Weaknesses

### 1. Authentication & Weak Passwords
- Authentication = proving identity
- Methods:
  - Something you know (password)
  - Something you are (biometrics)
  - Something you have (OTP/device)

#### Problem
- Users choose weak or predictable passwords:
  - Simple numbers (123456)
  - Common words (password, monkey)
  - Keyboard patterns (qwerty)

#### Risk
- Attackers can easily guess passwords and gain access

#### Key Learning
- Use strong, unique passwords for each account

### 2. Weak File Permissions
- Not everyone should access every file
- Based on **principle of least privilege**

#### Principle of Least Privilege
> Give only the minimum access required

#### Risks
- Unauthorized users can:
  - Read sensitive files → breaks confidentiality
  - Modify files → breaks integrity

### 3. Malicious Programs (Malware)

#### Types & Impact
- **Trojan:** Gives attacker access to your system
- **Ransomware:**
  - Encrypts your files
  - Makes them unusable
  - Demands payment to restore access

#### Impact on CIA
- Confidentiality → attacker reads files  
- Integrity → attacker modifies files  
- Availability → files become inaccessible  

---

## Practical Attack Concepts

### Gaining Access
- Attackers may :
  - Trick users into running malicious files
  - Guess usernames and passwords

### Remote Login (SSH)
- Used to connect to another machine remotely
- Requires :
  - Username
  - Password

### Key Commands (Linux Example)

- Command : `ssh username@ip` - Connect to remote machine
- Command : `whoami` - Check current user
- Command : `ls` - List files
- Command : `cat filename` - Read file contents
- Command : `history` - View previously executed commands

---

## Important Attack Techniques

### Password Guessing
- Trying common passwords based on patterns
- Works if users use weak credentials

### Human Mistakes
- Writing passwords on sticky notes
- Reusing passwords
- Typing sensitive info in terminal history

### Privilege Escalation
- Moving from a normal user to admin/root access

#### Commands :

- `su - username` - Switch user
- `su - root` - Attempt admin/root access

---

## Key Takeaways
- OS security is about protecting :
  - Data
  - Access
  - System availability

- Most attacks succeed because of :
  - Weak passwords
  - Poor permissions
  - Careless user behavior
  
- The OS is the control layer of everything
- If it’s compromised → everything is compromised
- Security is not just technical :
  - It heavily depends on user behavior
- Small mistakes (like weak passwords) can lead to full system takeover
