# Linux CLI Basics

## Introduction
Linux plays a huge role in cybersecurity—running servers, powering tools, and supporting security operations. To work effectively in this environment, 
understanding the Command-Line Interface (CLI) is essential.

## What is CLI ?
**CLI (Command-Line Interface)** is a text-based way to interact with a system by typing commands instead of using a graphical interface.

### Why use CLI?
- Faster than GUI
- More control over the system
- Required for many cybersecurity tools

---

## Terminal Basics

The terminal allows you to execute commands directly on the system.

### Navigation Commands

**1. Check Current Directory**

- `pwd` : Displays your current working directory.

**2. List Files and Directories**

- `ls` : Shows files and folders in the current directory.

- `ls -l` : Displays detailed information (permissions, size, date).

- `ls -al` : Shows all files, including hidden ones (files starting with .)

**3. Change Directory**

- `cd <directory>` : Move into a directory.

- `cd ..` : Go back one level.

**4. Searching for Files**

- `find <path> -name <filename>` : Find a File

> Example : find ~ -name mission_brief.txt

**5. Reading Files**

- `cat <filename>` : View File Content

> Example : cat mission_brief.txt

### System Information Commands

**1. Who Are You Logged in As ?**

- `whoami` : current user

**2. What System Are You On ?**

- `uname -a` : Displays kernel version, system architecture, and more.
- `uname` : Shows only the OS name.

**3. Disk Usage**
- `df -h` :  check disk usage or available space
