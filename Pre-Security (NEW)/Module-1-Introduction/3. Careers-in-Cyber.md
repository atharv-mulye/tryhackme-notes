# Careers in Cyber

This section provides an overview of common roles in the cybersecurity field, along with their primary responsibilities and focus areas.

Cybersecurity careers can broadly fall into offensive, defensive, investigative, and engineering domains.

---

## 1. Security Analyst

### Summary

A Security Analyst is responsible for monitoring and protecting an organisation’s systems and data. They assess security posture, identify risks, and recommend improvements.

### Key Responsibilities

- Analyse the organisation’s cybersecurity posture  
- Monitor alerts and investigate suspicious activity  
- Document security findings and remediation steps  
- Develop security plans based on emerging threats and trends  

---

## 2. Security Engineer

### Summary

A Security Engineer designs, implements, and maintains security controls to protect infrastructure, networks, and applications.

### Key Responsibilities

- Design and implement security systems and controls  
- Test and validate security mechanisms  
- Monitor infrastructure for vulnerabilities  
- Strengthen system configurations and architecture  

---

## 3. Incident Responder

### Summary

An Incident Responder focuses on detecting, containing, and mitigating active cyberattacks while minimizing impact on the organisation.

### Key Responsibilities

- Develop and maintain incident response plans  
- Investigate live security incidents  
- Contain and eradicate threats  
- Produce post-incident reports and lessons learned  
- Improve metrics such as MTTD (Mean Time to Detect) and MTTR (Mean Time to Respond)  

---

## 4. Digital Forensics Examiner

### Summary

A Digital Forensics Examiner investigates cyber incidents by collecting and analysing digital evidence to determine what occurred.

### Key Responsibilities

- Collect digital evidence while maintaining chain-of-custody  
- Analyse disk images, logs, and memory dumps  
- Reconstruct timelines of attacks  
- Prepare detailed forensic reports for legal or corporate use  

---

## 5. Malware Analyst

### Summary

A Malware Analyst studies malicious software to understand its behavior, capabilities, and impact.

### Key Responsibilities

- Perform static analysis of malware binaries  
- Conduct dynamic analysis in controlled sandbox environments  
- Identify indicators of compromise (IOCs)  
- Document findings and recommend detection strategies  

---

## 6. Penetration Tester

### Summary

A Penetration Tester (ethical hacker) simulates cyberattacks to identify vulnerabilities before malicious actors can exploit them.

### Key Responsibilities

- Conduct security testing on networks and applications  
- Perform vulnerability assessments and audits  
- Exploit weaknesses in a controlled environment  
- Provide actionable remediation recommendations  

---

## 7. Red Teamer

### Summary

A Red Teamer emulates real-world adversaries to test an organisation’s detection and response capabilities.

### Key Responsibilities

- Simulate advanced attack scenarios  
- Exploit vulnerabilities and attempt to maintain persistence  
- Evaluate blue team detection capabilities  
- Deliver detailed reports to improve overall security resilience  

---

## Key Takeaway

Cybersecurity offers diverse career paths across offensive, defensive, investigative, and engineering domains. Each role contributes to strengthening an organisation’s security posture in different ways.

Understanding these roles helps in identifying personal interests and choosing a focused career path within cybersecurity.
