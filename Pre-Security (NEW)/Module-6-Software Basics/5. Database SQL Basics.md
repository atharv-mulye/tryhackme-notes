# Database SQL Basics

## Introduction

### What is Data ?
- Data refers to raw information that a computer can store and process.
- Examples include names, numbers, prices, dates, and text.
- Computers use data to perform operations and generate useful results.

### Why Data Storage Matters
- When a computer is running, it uses memory (RAM) to handle data temporarily.
- Once the system is turned off, this temporary data is lost.
- To keep information safe and usable later, it must be stored permanently.

### What is a Database ?
- A database is a system designed to store data in an organised and structured way.
- It allows users and programs to :
  - Store large amounts of data
  - Retrieve data quickly
  - Update or manage data efficiently
- Unlike simple files, databases are optimised for searching and handling complex queries.

### Why Databases are Important
- As data grows, managing it manually becomes slow and error-prone.
- Databases solve this problem by :
  - Keeping data organised
  - Allowing fast searches
  - Reducing duplication
  - Improving accuracy

### What is SQL ?
- SQL (Structured Query Language) is used to interact with databases.
- It allows users to :
  - Retrieve data
  - Filter specific information
  - Sort results
  - Modify stored data

### Basic Structure of Data in Databases
- Data is stored in tables
- Each table consists of :
  - **Columns** → define the type of data
  - **Rows** → contain actual records

### Summary
- Data is essential for computer operations.
- Databases store data permanently and in an organised way.
- SQL is the tool used to communicate with databases.
- Understanding these basics is the foundation for working with data systems.

## Understanding Tables, Rows, and Columns (Detailed Notes)

### What is a Table ?
- A table is the basic structure used to store data in a database.
- It looks similar to a spreadsheet with organised rows and columns.
- Each table holds data related to a specific topic (e.g., orders, users).

### What are Columns ?
- Columns define the type of data stored.
- Each column has a name (also called a field).
- All values in a column follow the same format or category.

#### Examples :
- `id` → unique identifier
- `drink` → name of the item
- `price` → cost of the item
- `time` → when the order was placed

> Think of columns as labels describing what kind of data is stored.

### What are Rows ?
- Rows represent a single, complete record in a table.
- Each row contains values for every column.

#### Example Row :
| id | drink  | price | time   |
|----|--------|-------|--------|
| 1  | Coffee | 100   | 10:00  |

> This row represents one full entry (one order).

### Key Differences

| Feature | Column | Row |
|--------|--------|-----|
| Purpose | Defines data type | Stores actual data |
| Direction | Vertical | Horizontal |
| Example | price, drink | One full order |

### Important Concepts
- A table can have many rows but fixed columns.
- Adding new data → adds a new row.
- Removing data → removes a row only.
- Columns remain the same unless the structure is changed.

### Why This Structure Matters
- Makes data easy to read and manage
- Allows fast searching and filtering
- Keeps data consistent and organised

### Final Understanding
- **Table** → collection of data
- **Column** → type/category of data
- **Row** → one complete record

## SQL Queries 

### What is a Query?
- A query is a request made to a database to get specific information.
- Instead of manually searching through data, queries let the computer do the work.
- Queries do not change data unless explicitly told to (in basic usage, they only display results).

## Core SQL Commands

### 1. SELECT – Retrieve Data
- Used to choose what data you want to see.

```sql
SELECT * FROM Orders;
```
> `*` means all columns

### 2. FROM – Specify Table
- Defines which table the data should come from.
```
SELECT * FROM Orders;
```
> Data is taken from the Orders table

### 3. Selecting Specific Columns
- You can choose only required columns instead of all data.
```
SELECT drink, price FROM Orders;
```
> Output will only show drink and price

### 4. WHERE – Filter Data
- Used to display only rows that match a condition.
```
SELECT * FROM Orders WHERE drink = 'Coffee';
```
> Shows only rows where drink is Coffee

### 5. ORDER BY – Sort Data
- Used to arrange results in a specific order. <br>

Ascending (default)
```
SELECT * FROM Orders ORDER BY price;
```
Descending
```
SELECT * FROM Orders ORDER BY price DESC;
```

### 6. Combining Commands
- Multiple conditions can be used together.
```
SELECT * FROM Orders
WHERE drink = 'Coffee'
ORDER BY price DESC;
```
> Filters coffee orders and sorts them from highest to lowest price

### Key Points
- Queries help retrieve data quickly
- They reduce manual effort
- Can filter and sort data easily
- Can be combined for more precise results

### Final Understanding
- SELECT → what to show
- FROM → where to get data
- WHERE → which data to filter
- ORDER BY → how to arrange results
