# Python Demo 

## Introduction

- Python is a programming language used to write programs.
- It is :
  - High-level → easy to understand
  - General-purpose → used for many things (web, automation, AI, etc.)

- In this demo, we build a simple “Guess the Number” game :
  - Computer picks a number (1–20)
  - User keeps guessing
  - Program tells if guess is too high or too low
  - Stops when the correct number is guessed

## Variables 

- Variables are used to store data (values) in a program.

**Code :**
<pre>
import random  # gives us tools for picking random numbers

secret = random.randint(1, 20)  # a <= secret <= b
tries = 0
guess = 0  # start with a value that cannot be the secret (since secret is 1..20)

print("I'm thinking of a number between 1 and 20")

text = input("Take a guess: ")  # input() returns text (a string)
guess = int(text)  # convert the text to a number

tries = tries + 1  # add 1 try
</pre>
In this program : 

- We use 3 variables :
    - secret → stores the random number
    - guess → stores user input
    - tries → counts number of attempts
- Python offers the random.randint() method, which returns a random integer within the specified bounds

## Conditional Statements

- Used to make decisions in a program.
- Program runs different code based on conditions.

### Syntax

if condition : <br>
elif condition : <br>
else :

**Code :**

<pre>
import random  # gives us tools for picking random numbers

secret = random.randint(1, 20)  # a <= secret <= b
tries = 0
guess = 0  # start with a value that cannot be the secret (since secret is 1..20)

print("I'm thinking of a number between 1 and 20")

text = input("Take a guess: ")  # input() returns text (a string)
guess = int(text)  # convert the text to a number

tries = tries + 1  # add 1 try

# Give a hint using if / elif / else.
if guess < 1 or guess > 20:
    print("That number is out of range. Try again.")
elif guess < secret:
    print("Too low, try again.")
elif guess > secret:
    print("Too high, try again.")
else:
    print("You got it in", tries, "tries!")
</pre>

In this program :

- Compare user's guess with the secret number.
- `if` → first condition checked  
- `elif` → checked if above is false  
- `else` → runs if all conditions are false  

Operators used : 
- `<` → less than  
- `>` → greater than  
- `==` → equal  
- `!=` → not equal  
- `or` → any condition true  

### Key Idea
- Conditions return True or False
- Program decides what to do based on that
> Conditional statements help the program make decisions

## Iterations (Loops)

- Iteration means repeating a block of code multiple times.
- It is used when we want the program to keep running until a condition is met.

### Why used here
- The user needs multiple chances to guess the number.
- So the program repeats until the correct guess is made.


### While Loop

while condition :


- Runs as long as the condition is true.
- Stops when the condition becomes false.

**Code :**

<pre>
import random  # gives us tools for picking random numbers

# ----------------------------
# Guess the Number (Beginner Demo)
# ----------------------------
# The computer picks a secret number.
# The player keeps guessing until they find it.

secret = random.randint(1, 20)  # a <= secret <= b
tries = 0
guess = 0  # start with a value that cannot be the secret (since secret is 1..20)

print("I'm thinking of a number between 1 and 20")

# Repeat until the user guesses the secret number.
while guess != secret:
    text = input("Take a guess: ")  # input() returns text (a string)
    guess = int(text)  # convert the text to a number
    
    tries = tries + 1  # add 1 try

    # Give a hint using if / elif / else.
    if guess < 1 or guess > 20:
        print("That number is out of range. Try again.")
    elif guess < secret:
        print("Too low, try again.")
    elif guess > secret:
        print("Too high, try again.")
    else:
        print("You got it in", tries, "tries!")
</pre>

### Condition used

`guess != secret`

- != means not equal to
- Loop runs until guess becomes equal to secret

### Example
- secret = 10
- guess = 5 → loop runs
- guess = 10 → loop stops

### Key Idea
- The program keeps asking for input and checking it again and again until the correct answer is found.

### In short
- Iteration is used to repeat code until a condition becomes false
