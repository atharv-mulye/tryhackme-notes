## Prompting User for Input

- To get input from the user, JavaScript uses `readline` module with promises.
- Example of reading input and converting it to a number:

```javascript
import * as readline from "node:readline/promises";
import { stdin as input, stdout as output } from "node:process";

const rl = readline.createInterface({ input, output });

try {
    const text = await rl.question("Take a guess: "); // user types input as text
    let guess = parseInt(text, 10); // convert text to integer
} finally {
    rl.close(); // close the input interface
}
```
await rl.question() pauses execution until the user enters a value.
parseInt(text, 10) converts the string to a base-10 number.
Always close the readline interface with rl.close().

## Conditional Statements

- Conditional statements let the program make decisions based on conditions.
- JavaScript uses `if`, `else if`, and `else` for this purpose.

Example :

```javascript
if (guess < 1 || guess > 20) {
    console.log("That number is out of range. Try again.");
} else if (guess < secret) {
    console.log("Too low, try again.");
} else if (guess > secret) {
    console.log("Too high, try again.");
} else {
    console.log("You got it in", tries, "tries!");
}
```
if checks the first condition.
else if checks the next condition if previous if is false.
else runs if all previous conditions are false.
|| means “or” in JavaScript.

## Iterations (Loops)

- Loops allow repeating a block of code until a condition is met.
- In JavaScript, `while` loops are commonly used for this.

Example :

```javascript
while (guess !== secret) {
    const text = await rl.question("Take a guess: "); // get input
    guess = parseInt(text, 10); // convert input to number
    tries = tries + 1; // increment tries

    if (guess < 1 || guess > 20) {
        console.log("That number is out of range. Try again.");
    } else if (guess < secret) {
        console.log("Too low, try again.");
    } else if (guess > secret) {
        console.log("Too high, try again.");
    } else {
        console.log("You got it in", tries, "tries!");
    }
}
```
while CONDITION runs the loop as long as CONDITION is true.
!== means “not equal” in JavaScript.
Loop keeps repeating until the user guesses the correct number.

**Code :**

```
import * as readline from "node:readline/promises";
import { stdin as input, stdout as output } from "node:process";

const rl = readline.createInterface({ input, output });

try {
    const secret =
        Math.floor(Math.random() * (20)) + 1; // 1 <= secret <= 20
    let tries = 0;
    let guess = 0; // start with a value that cannot be the secret (since secret is 1..20)

    console.log("I'm thinking of a number between 1 and 20");

    // Repeat until the user guesses the secret number.
    while (guess !== secret) {
        const text = await rl.question("Take a guess: "); // rl.question() returns text (a string)
        guess = parseInt(text, 10); // convert the text to a number

        tries = tries + 1; // add 1 try

        // Give a hint using if / else if / else.
        if (guess < 1 || guess > 20) {
            console.log("That number is out of range. Try again.");
        } else if (guess < secret) {
            console.log("Too low, try again.");
        } else if (guess > secret) {
            console.log("Too high, try again.");
        } else {
            console.log("You got it in", tries, "tries!");
        }
    }
} finally {
    rl.close();
}
```
