# Search Skills

## Introduction

Searching is one of the most fundamental skills in cybersecurity. During penetration testing, incident response, threat hunting, or vulnerability assessment, security professionals constantly rely on trusted online resources to gather intelligence, identify vulnerabilities, verify threats, and understand tools.

Knowing **where to search** is just as important as knowing **what to search for**. Resources such as Shodan, VirusTotal, CVE databases, official documentation, Linux manual pages, and GitHub help security professionals perform reconnaissance, validate findings, research vulnerabilities, and solve technical problems efficiently.

---

## Shodan

### What is Shodan ?

Shodan is a search engine that indexes internet-connected devices and services instead of web pages.

Unlike traditional search engines that crawl websites, Shodan continuously scans public IP addresses and records information exposed by network services.

It helps security professionals identify :

- Publicly accessible servers
- IoT devices
- Industrial Control Systems (ICS)
- Firewalls
- Routers
- Web servers
- Databases
- Cameras
- Network appliances

## Why is Shodan Useful ?

### Offensive Security

- Identify exposed services
- Discover outdated software versions
- Find vulnerable devices
- Perform reconnaissance before penetration testing

### Defensive Security

- Detect accidentally exposed assets
- Audit an organization's attack surface
- Verify open ports and services
- Monitor internet-facing infrastructure

## How Shodan Works

1. Continuously scans public IP addresses.
2. Connects to common network ports.
3. Collects service banners.
4. Indexes gathered information.
5. Allows users to search using filters.

### Common Search Filters

| Filter | Purpose | Example |
|---------|----------|---------|
| `country` | Search devices in a specific country | `country:US` |
| `port` | Find devices exposing a specific port | `port:22` |
| `org` | Search by organization or ASN | `org:Amazon` |
| `hostname` | Search specific domains or hostnames | `hostname:example.com` |

## VirusTotal

### What is VirusTotal ?

VirusTotal is an online malware analysis platform that checks files, URLs, IP addresses, domains, and hashes using multiple antivirus engines and security vendors.

Instead of relying on a single antivirus product, VirusTotal aggregates results from many security engines.

<img width="1504" height="848" alt="image" src="https://github.com/user-attachments/assets/e43243c8-1c08-4a76-9e7e-c883c20a5e88" />

## What Can Be Scanned ?

- Files
- URLs
- Domains
- IP addresses
- File hashes

## Why Use VirusTotal ?

- Verify suspicious files
- Check malicious websites
- Investigate malware samples
- Gather threat intelligence
- Detect known malicious hashes

## How It Works

1. Submit a file or URL.
2. VirusTotal scans it using multiple security engines.
3. Results are combined into a single report.
4. Detection ratio indicates how many engines flagged it.

Example:

```text
Detected by:
25 / 72 engines
```

This means 25 security engines identified the file as malicious.

## Important Note

A clean VirusTotal report **does not guarantee safety**.

Reasons include:

- New malware may not yet be detected.
- Signature databases may be outdated.
- Some malware targets specific environments.

Always perform additional analysis when necessary.

## Common Vulnerabilities and Exposures (CVE)

### What is CVE ?

Common Vulnerabilities and Exposures (CVE) is a standardized system used to uniquely identify publicly known security vulnerabilities.

Each vulnerability receives a unique identifier.

Example:

```text
CVE-2025-55182
```

Format:

```text
CVE-Year-Unique Number
```

<img width="1327" height="832" alt="image" src="https://github.com/user-attachments/assets/50a80baf-ab9f-4977-addb-d5439a35e16e" />

## Purpose of CVE

Provides a common reference that allows:

- Security researchers
- Software vendors
- Penetration testers
- Security tools

to refer to the same vulnerability consistently.

## Why CVEs Matter ? 

They help organizations:

- Track vulnerabilities
- Prioritize patches
- Share security information
- Automate vulnerability management

## CVSS (Common Vulnerability Scoring System)

### What is CVSS ?

CVSS is a standardized scoring system that measures the severity of a vulnerability.

Scores range from:

```text
0.0 → 10.0
```

Higher scores indicate greater risk.

## Factors Considered

### Impact

Measures potential damage if exploited.

Examples:

- Data theft
- Remote code execution
- Privilege escalation

### Exploit Complexity

Measures how difficult exploitation is.

Lower complexity generally means higher risk.

### Availability

Considers how easily attackers can exploit the vulnerability in real-world environments.

## Why CVSS Matters

Organizations use CVSS scores to prioritize remediation.

Higher severity vulnerabilities should generally be addressed first.

## Exploit Database (Exploit-DB)

### What is Exploit-DB ?

Exploit-DB is a public database containing:

- Exploits
- Proof of Concept (PoC) code
- Security papers
- Vulnerability references

### Proof of Concept (PoC)

A PoC demonstrates that a vulnerability can be successfully exploited.

Its purpose is to:

- Validate the vulnerability
- Help researchers understand exploitation
- Assist defenders in testing patches

A PoC is **not necessarily a complete attack tool**.

## Technical Documentation

### Why Documentation Matters ? 

Official documentation is the most reliable source for:

- Installation instructions
- Configuration
- Command syntax
- Feature explanations
- Troubleshooting

Using official documentation reduces errors caused by outdated or incorrect third-party tutorials.

## Linux Manual Pages (man)

### What are Man Pages ?

Man pages are built-in Linux documentation available directly from the terminal.

They explain:

- Commands
- Options
- Syntax
- Examples
- Usage

## Syntax

```bash
man <command>
```

Example:

```terminal
user@thm$ man nc
NC
                                                                                  
NAME
       nc — arbitrary TCP and UDP connections and listens

SYNOPSIS
       nc  [-46bCDdFhklNnrStUuvZz]  [-I  length]  [-i  interval]  [-M  ttl] [-m minttl] [-O length] [-P proxy_username] [-p source_port] [-q seconds] [-s sourceaddr] [-T keyword] [-V rtable] [-W recvlimit] [-w timeout]
          [-X proxy_protocol] [-x proxy_address[:port]] [destination] [port]
```

Displays the manual for Netcat.

## Why Use Man Pages ?

Useful for:

- Learning unfamiliar commands
- Understanding available options
- Troubleshooting command usage
- Working without internet access

## GitHub for Security Research

### Why GitHub is Useful ? 

GitHub is widely used by security researchers to share:

- Proof of Concept exploits
- Security tools
- Detection scripts
- Technical write-ups
- Vulnerability research

Searching for a CVE often reveals community-created resources.

Example:

```text
CVE-2026-1337
```

may return:

- Exploit code
- Scanner scripts
- Technical analysis
- Detection methods

## Important Security Consideration

Never blindly execute code downloaded from GitHub.

Some repositories may contain:

- Incomplete PoCs
- Fake exploits
- Malicious code

Always:

- Review the source code
- Verify the author's credibility
- Test safely in an isolated environment
- Avoid executing unknown scripts on production systems

## Key Takeaways

- **Shodan** indexes internet-connected devices and exposed services.
- **VirusTotal** checks files, URLs, domains, IPs, and hashes using multiple security engines.
- **CVE** provides unique identifiers for publicly disclosed vulnerabilities.
- **CVSS** measures vulnerability severity to help prioritize remediation.
- **Exploit-DB** hosts public exploits and Proof of Concept (PoC) code.
- **Official documentation** is the most reliable source for learning tools and troubleshooting.
- **Linux man pages** provide built-in command documentation directly in the terminal.
- **GitHub** is valuable for security research but downloaded code should always be verified before execution.
