# Linux Fundamentals Part 1

## Introduction
Linux is an operating system like Windows or macOS but often more lightweight and flexible.  
It powers many devices, including :  
- Web servers and websites  
- Car infotainment systems  
- Point-of-sale (PoS) terminals  
- Critical infrastructure (e.g., traffic lights, industrial sensors)  

This guide introduces :  
- Basic Linux commands  
- Filesystem navigation  
- Searching for files  
- Shell operators for advanced command execution  

---

## Linux Background

### Where Linux is Used
Linux is everywhere, even if you don’t notice:  
- Servers running websites and web apps  
- Android devices  
- Home appliances like smart TVs or fridges  
- Critical systems where reliability is crucial  

### Linux Distributions
- "Linux" is a broad term, there are many distributions (distros).  
- Popular ones include Ubuntu and Debian.  
- Distros can be customized for servers, desktops, or lightweight environments.  
- Minimal systems can run with very little RAM (e.g., Ubuntu Server: 512MB).

## Basic Commands

| Command  | Description                              | Example |
|----------|------------------------------------------|---------|
| echo  | Outputs text to the terminal             | echo "Hello World" |
| whoami | Shows the current logged-in user         | whoami |

**Notes :**  
- `echo` prints text. Use quotes for multiple words.  
- `whoami` is useful to confirm your username, especially on shared systems.  

---

## Filesystem Navigation

| Command | Description | Example |
|---------|------------|---------|
| ls    | Lists files and directories in the current location | ls or ls Documents |
| cd    | Changes the current directory | cd Documents |
| pwd   | Prints the full path of the current directory | pwd |
| cat   | Displays the contents of a file | cat todo.txt |

**Notes :**  
- Use `ls` to see what files/folders exist.  
- `cd folder_name` moves into that folder.  
- `pwd` helps track your location in the filesystem.  
- `cat filename` reads file contents; can be combined with paths: `cat /home/user/Documents/todo.txt`.  

---

## Searching for Files

### `find`
| Command | Description | Example |
|---------|------------|---------|
| find -name <filename> | Searches current directory and subdirectories for a file | find -name passwords.txt |
| find -name "*.txt" | Finds all .txt files | find -name "*.txt" |

**Notes :**  
- Wildcards (`*`) allow partial name searches.  
- Great for quickly locating files without manually browsing directories.  

### `grep`
| Command | Description | Example |
|---------|------------|---------|
| grep "<text>" <file> | Searches for specific text inside a file | grep "81.143.211.90" access.log |
| grep -R "<text>" <directory> | Searches recursively in all files and subdirectories | grep -R "PRETTY_NAME" /etc/ |

**Notes :**  
- `grep` finds text inside files.  
- `-R` lets you search through directories recursively.  
- Useful for logs, configuration files, or any large text files.

## Shell Operators

| Operator | Description | Example |
|----------|------------|---------|
| &     | Runs a command in the background | long_task & |
| &&    | Runs the next command only if the previous succeeds | mkdir new && cd new|
| >      | Redirects output to a file (overwrites) | echo hello > file1 |
| >>     | Appends output to the end of a file | echo world >> file1 |

**Notes :**  
- `&` frees up your terminal while the command runs.  
- `&&` is a chain operator to combine commands safely.  
- `>` creates or overwrites a file.  
- `>>` adds to a file without deleting existing content.  

---

## Summary
- Linux is lightweight, versatile, and widely used.  
- Key commands to remember:  
  - `echo`, `whoami` – output text and check user  
  - `ls`, `cd`, `pwd`, `cat` – navigate and read the filesystem  
  - `find`, `grep` – search files and text efficiently  
  - `&`, `&&`, `>`, `>>` – control command execution and output  

- Regular practice in a terminal will build confidence and speed.  
- These fundamentals form the base for all Linux work.
